# Cognition Tree 可用版

运行 `./start.sh` 启动，按 Ctrl+C 停止。启动脚本不接受模式参数。
需要 Bash 与 Node.js 22.18.0 或更高版本；依赖已经包含在运行包中。
地址以“设置 → 服务”的配置为准，初始地址为 http://127.0.0.1:3001。

`./ctn` 是 API v4 客户端；使用步骤见源码仓库的 API 与 CLI 集成文档。
完整源码、测试、开发入口及维护文档位于相邻的 `repo-dev` 源码仓库。
`release.json` 记录本包对应的完整 Git 提交、锁文件摘要和文件校验清单。

正式配置保存在本目录的 `.cognition-tree/bootstrap-v1`；内容位置以其中的数据根配置为准。
升级必须先停止服务并备份固定控制区、当前数据根和旧运行包。新包不包含也不覆盖这些数据。
本目录是生成结果；修改应在源码仓库中提交，再显式发布经过验证的新运行包。
