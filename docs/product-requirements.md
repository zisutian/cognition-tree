# 产品需求

本文件定义当前能力、用户可见行为与安全承诺。模块关系见[模块边界](architecture.md)，
交互见[界面规范](ui-guidelines.md)，操作入口见[快速入门](getting-started.md)。
协议、数据格式和恢复算法由各开发专题详细说明。

## 1. 定位

认知树是服务端保存内容的可配置语法结构化笔记应用，以 `.ctn` 原文、缩进、语法与引用组织知识。
产品面向单个使用者及其受控设备，不引入多用户、角色权限或多人协作状态。

## 2. 平级内容领域

| 领域 | 用户能力 |
|---|---|
| Workspace | 管理多个普通笔记库，组织目录、笔记、语法和引用 |
| Journal | 全局日记，一天多条，标题按日期和当日递增序号生成，不能重命名 |
| Todo | 全局代办，集合内以 CTN 层级组织任务，支持完成历史与周期 |

Journal 和 Todo 不随普通仓库切换，不能创建第二份、删除整个内置库或将其变成普通仓库。
没有健康普通仓库时，日记、代办、仓库管理和设置仍可使用。

日记每天最多 9999 条，删除不复用序号；编辑器只显示正文。
代办集合可以新建、重命名、删除和排序，集合内部标题不进入可编辑正文。任务父子独立完成，
勾选不改写正文符号，完成项保留原位置并划线；任务结构提供勾选与定位，不提供任务拖动。

周期任务支持按每 N 天、每 N 周的 ISO 星期集合、每 N 月的日期重复，月内缺失日期取最后一天。
周期使用运行环境本地日历，不保存时区或零点任务；始终对应同一块，不生成正文副本。
错过次数计入总数但不积压，勾选作用于最近一次已到期项，下一期到达后显示未完成。
修改或停止规则从下一天开始新阶段并保留历史；普通已完成任务首次启用周期时记录当天完成。

## 3. Workspace 对象

- 笔记：可见 `.ctn` 文件只保存正文，文件名对应标题；内部块元数据不占用编辑区。
- 文件夹：对应真实目录，用于组织、移动和指定新建落点。
- 块：由源码结构识别，是选择、移动、引用和整理的单位；具有稳定身份与创建/修改时间。
- 引用：支持块与笔记引用，重复标题返回歧义候选，不任意取一个；允许自引用。

Journal 的 `[[YYYY-MM-DD-0001]]` 指向仓内日记，`[[仓库名:笔记名]]` 指向普通仓库的整篇笔记。
普通仓库或笔记重命名不自动改写独立日记，日记跨仓引用不进入普通引用图谱。

多行块保持完整、可见、可选择和可编辑的源码，不转换为卡片或保护区域。
解析和编辑边界见[CTN 分析流水线](ctn-analysis-pipeline.md#多行源码)。

## 4. 语法

普通仓库拥有有序语法目录。“打开编辑”和“启用”分别操作；新建复制当前编辑文件但不自动启用。
没有语法或未启用时显示原文，结构分析不套用默认规则。空目录新建使用明确初始模板，仍需用户启用。
无效草稿需修复或撤销后才能离开；启用语法与全仓元数据调整为一次原子修改。

系统语法包含日记与代办。日记允许配置正文、块及受保护引用规则；代办固定任务名称、符号与语义，
允许修改背景和内容颜色。两者不展示标题规则，普通笔记可以配置标题规则。
受保护字段不能修改或删除，自定义规则支持完整编辑与删除。草稿预览、保存后的语法与编辑器
显示保持一致；精确颜色和失效语义见 CTN 专题。

## 5. 名称

普通笔记、文件夹、仓库和 Todo 集合使用统一可移植名称规则：写入前 trim、NFC、折叠连续
ASCII 空格；只允许 Unicode 字母、组合标记、数字、内部普通空格、连字符和下划线。
唯一键使用 NFKC 和 en-US lowercase。

新建与重命名拒绝非法名称，“日记”和“代办”为仓库保留名。既有不合规名称保持可读并提示诊断，
由用户重命名，不自动改写。语法名称和任务正文不使用这组限制。

## 6. Repository 与存储

普通仓库位于服务端本地文件系统或容器持久卷；远程浏览器访问不改变存储位置。
用户可直接管理可见目录与 `.ctn` 正文，非 `.ctn` 文件不被应用改写或删除。
Repository 管理目录、位置、故障、恢复及危险操作，普通内容编辑留在各领域。

三个领域的数据和页面状态独立，一个领域故障或重置不能影响另一个。损坏或不支持的内容原样
保留并关闭写入，不自动清空或伪装为空库。格式与存储提交点见[内容一致性](content-consistency.md)。

页面草稿先保存在内存，再异步同步到服务端。非重叠修改可合并，重叠修改进入可恢复冲突，
远端结果不能覆盖尚未处理的本地修改。冲突期间可以继续编辑，全部冲突消除后自动恢复同步；
显式解决时暂时冻结修改，并完整保护将被丢弃的内容，不以部分副本冒充另存成功。
服务不可用或读取冲突详情失败时显示错误和重试入口。刷新或关闭页面不恢复未同步草稿及冲突。

## 7. Activities 与 Problems

工作台提供笔记、日记、代办、语法、智能体、搜索、仓库和设置八项能力。
笔记中的编辑、结构和图谱模式共享当前笔记及编辑历史。健康仓库重扫从笔记工作区进入，
期间暂停相关修改，失败进入问题区。

问题区统一呈现领域诊断、状态故障和操作错误，重复操作错误聚合。诊断随源状态恢复消失，
操作错误可单独关闭，刷新后清空。定位只进入对应内容或恢复入口，不自动执行修改。
布局、筛选和反馈位置见[界面规范](ui-guidelines.md#问题与反馈)。

## 8. Agent

Agent 是所有者控制的内容修改入口。新会话使用设置中的默认 Profile，创建时选择一种硬范围：

| 领域 | 允许的范围 |
|---|---|
| Workspace | 一个仓库、稳定文件夹及其后代，或精确笔记 |
| Journal | 全域或一组精确日记 |
| Todo | 全域或一组精确集合 |

范围和 Profile 在会话中不能扩大或替换；范围根删除后会话不可用。发送、批准和删除确认前，
客户端先同步范围内已加载草稿，同步失败或冲突阻止操作。

模型修改先形成单个存储内的只读 proposal，由领域事实生成可审查差异，再由所有者整批批准或拒绝；
删除需要独立二次确认。跨存储意图顺序形成多份提案。基线版本变化后提案过期，不能自动合并或重算。
提交结果无法确认时显示“结果待确认”，不能再次批准或重放，需读取权威内容核对。

模型只获得范围内的读取、搜索、语法说明和领域动作。写入正文前必须读取当前语法，语法变化后
重新读取。非法调用不得执行，工具协议不伪装成对话；原始 reasoning 不进入界面、事件、日志或审计。
无有效正文、长度耗尽或协议不完整均明确失败，不隐藏重试或回退。

对话、压缩摘要和会话仅驻留服务内存；重启、空闲 1 小时、存活 24 小时或主动删除后丢失会话。
持久提交凭据与审计的保留语义见[服务运行](service-runtime.md#操作账本)。

Provider、Profile、模型参数和凭据在设置管理。发现、探测与符合性检查均显式进行，
不自动选模或修改配置；无效 Profile 显示原因。配置操作、登录及会话历史预算见[设置操作](settings.md#agent-provider-配置与认证)，
进程隔离、凭据事务和模型协议见[服务运行](service-runtime.md#agent-与模型进程)。

## 9. 服务设置与数据迁移

设置按对象编辑，未保存、基线过期或提交中时阻止应用内导航；外部刷新和提交失败保留输入。
保存或放弃后不自动执行先前被阻止的跳转，即时偏好与需提交配置区别见[设置操作](settings.md)。

网页与 API 由同一个 Node origin 提供。用户从设置管理监听、端口、路径、认证、审计和 Provider，
不通过客户端 JSON 或环境变量维护第二份配置。局域网访问需要已激活的 owner 凭据和 HTTPS origin，
TLS 由外部代理处理。凭据轮换先交付新密钥，确认保存后再激活，不提前撤销旧凭据。

数据根迁移先同步内容、排空写入、校验复制结果，再切换配置指针。未提交失败继续使用源，
结果未知时保持维护并对账；无法确认权威目录时提供诊断，保留源和已分配目标。
当前迁移范围、限制与恢复入口见[部署与恢复](deployment.md#数据控制区与迁移)。

## 10. 当前边界

搜索覆盖普通仓库、日记和代办，页面仅按这三个领域筛选，不提供逐仓库或更新时间筛选。
公开查询仍可限定普通仓库 ID；结果按稳定资源与块导航。单个来源故障不阻断健康来源，
游标失效后使用当前条件重新搜索。

Todo 不包含截止日期、优先级、备注、筛选或跨集合任务移动。
本机内容 API 支持名称查询、精确修改、仓库管理、任务与语法操作，单次版本校验提交，不自动重试，
不提供跨领域事务；系统配置与凭据仍从设置操作。旧自动化与可信客户端令牌不再提供访问能力，
不提供远程 API 令牌。调用契约见[API 与 CLI 集成](api-integration.md)。

项目不提供外部 MCP、专用手机契约、Dockerfile、镜像或 Compose；部署文档中的容器路径仅说明持久化要求。
