逐步构建流程


文档职责：

    只记录当前状态、已实现能力摘要、下一步顺序、验证命令和暂缓事项。
    不记录产品原则、详细需求、长期架构、样式规则和个人环境。


1. 当前状态

分支：

    web-docker-runtime

路线：

    浏览器前端 + 本机 Node HTTP 后端 + 本地文件仓库。
    桌面运行已剔除。
    Docker 容器化后移。

当前未提交工作：

    架构边界约定和 ctn-parser / ctn-syntax 成对命名。


2. 已实现能力

    本地文件仓库：workspace.json、notes/*.ctn、syntax/workspace.toml。
    HTTP 存储闭环：WorkspaceRepository、HTTP adapter、Node API、File Store。
    笔记与目录：笔记 CRUD、文件夹 CRUD、笔记移动。
    CTN 编辑：CodeMirror 原文编辑、Tab 层级、结构树和诊断。
    仓库语法：唯一 TOML 语法、受控编辑、前后端 parity tests。
    块迁移：双视图工作台，跨笔记移动整棵块子树。
    可视化：第一版笔记级引用图谱。
    界面：app / features / shell / workspace / ctn-parser / ctn-syntax / editor / storage 分层，VS Code 风格暗色主题。


3. 下一步顺序

1. SQLite / FTS5 派生索引。
2. 引用索引和链接查询。
3. 稳定块身份设计。
4. 时间演化图谱数据模型。
5. 标题和正文搜索。
6. Docker 后端容器化和 volume 持久化验证。
