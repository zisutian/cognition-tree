3. 近期实施顺序

3.1 工作区界面分化

目标：

    将笔记编辑、语法编辑和块迁移拆成不同主工作区形态，避免语法和迁移继续挤在笔记侧栏里。

步骤：

    notes / outline 保持当前笔记编辑器和结构树。
    syntax 使用中间主区承载完整 TOML 编辑器，右侧承载 profile 摘要、诊断和保存状态。
    migration 使用中间主区承载双栏块迁移工作台，右侧承载兼容性和迁移结果。
    左侧侧栏在 syntax 中只保留语法文件列表和新建/删除入口。
    左侧侧栏在 migration 中只保留迁移状态摘要。

小提交顺序：

    App 主工作区分支
    语法侧栏和语法主区拆分
    迁移侧栏和迁移主区拆分
    右侧详情区状态展示
    自动验证和界面审核

3.2 拖拽式块迁移

目标：

    在显式迁移闭环稳定后，复用同一套移动 API 接入拖拽。

步骤：

    增加双笔记结构面板或结构树拖放入口。
    拖拽只负责选择源块和目标位置。
    迁移仍复用领域层移动 API。

3.3 Docker 打包与部署验证

目标：

    将已经稳定的 HTTP 后端容器化，并验证 Docker volume 持久化。

步骤：

    增加 Dockerfile。
    增加 compose 文件。
    明确 volume 数据目录。
    验证容器重启后数据保留。
