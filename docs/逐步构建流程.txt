2. 日常开发命令

安装依赖：

    pnpm install

前端开发服务器：

    pnpm dev

桌面端开发模式：

    pnpm tauri dev

单元测试：

    pnpm test

类型检查：

    pnpm check

前端生产构建：

    pnpm build

Rust / Tauri 后端检查：

    cd src-tauri
    cargo check


3. 提交前检查

提交前至少运行：

    pnpm test
    pnpm check
    pnpm build
    cd src-tauri
    cargo check

再检查空白问题：

    git diff --check
