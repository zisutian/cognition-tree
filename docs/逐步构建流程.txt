2. 第一版闭环边界

第一版目标不是堆功能清单，而是先让核心认知树工作流闭合。

必须闭合：

    本地文件仓库可以保存和恢复笔记、目录树和仓库语法文件。
    用户可以创建、编辑、删除和移动笔记。
    用户可以创建、重命名、删除文件夹，并用文件夹组织笔记。
    用户可以编辑认知树原文，并用 Tab 缩进表达结构层级。
    当前笔记可以按仓库语法配置解析为结构树和诊断。
    仓库语法文件可以编辑，并影响仓库内所有笔记解析。
    用户可以在两篇笔记之间移动整棵块子树。
    块迁移界面必须让用户明确判断移动对象、子树范围和目标插入位置。

后移能力：

    搜索、导出、导入、链接、统计、同步、插件、桌面恢复和 AI 辅助整理。
    这些能力只有在笔记、语法和块迁移闭环稳定后再逐步扩展。


3. 当前主线

主线名称：

    VS Code 风格主题统一

目标：

    建立统一主题样式约定。
    全部界面按 VS Code 默认暗色风格收敛。
    颜色、字体、字号和字重由主题 token 与文档约定控制。
    消除浅色旧样式、黄绿暗色、过多线框和过多块状控件。

当前步骤：

    新增界面样式约定文档。
    新增全局 theme token。
    收敛 base、layout、sidebar、editor、outline、workspace 样式。
    验证通过后停下审核。

完成标准：

    笔记、语法、迁移和可视化界面都使用同一暗色主题。
    左侧栏、编辑区、详情区、输入框、按钮、列表和图谱不再出现浅色旧主题。
    字体、字号和字重符合 docs/界面样式约定.txt。
    语法高亮和图谱颜色只作为弱语义提示，不主导界面背景。
