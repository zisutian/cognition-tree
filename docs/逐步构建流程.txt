3. 近期实施顺序

3.1 Web / Docker 存储闭环

目标：

    浏览器前端通过 HTTP API 读写 Docker 后端文件库。

步骤：

    新增 HttpNoteRepository。
    让 useNoteWorkspace 使用 HTTP 存储适配器。
    保留浏览器 localStorage 适配器作为开发兜底或测试辅助。
    增加 Dockerfile。
    增加 compose 文件。
    明确 Docker volume 数据目录。
    验证刷新后数据保留。

3.2 默认语法代码实现

目标：

    代码实现与需求说明中的默认语法一致，不保留旧 marker 兼容入口。

步骤：

    同步 TypeScript 默认 profile。
    更新 CtnBlockType。
    增加 code 和 syntax-rule 类型。
    删除旧默认 marker。
    更新解析器测试。

3.3 解析器结构能力

目标：

    为块迁移和结构视图提供可靠范围信息。

步骤：

    增加 fenced code block 解析。
    增加行内结构 inlineSpans。
    增加块子树结束行信息 endLineNumber。
    保证代码块内部不解析 marker 和行内结构。

3.4 跨笔记块迁移底座

目标：

    支持不同笔记之间移动整棵块子树。

步骤：

    抽出块文本纯函数。
    增加 syntaxImports 数据模型。
    实现有效语法解析。
    实现跨笔记移动整棵块子树。
    实现缺失语法块引用随迁提示。

3.5 块迁移 UI

目标：

    先验证流程，再接入拖拽。

步骤：

    增加双笔记结构面板。
    先做点击式“从左移到右”。
    再在同一套移动 API 上接入拖拽交互。
