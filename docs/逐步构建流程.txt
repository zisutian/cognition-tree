2. 当前主线

主线名称：

    workspace manifest DTO 校验

目标：

    收紧 workspace.json 和 PUT /api/workspace 的数据边界。
    后端读取和保存 workspace 前显式校验 DTO shape。
    损坏或旧 schema 数据直接报错，不做静默修剪和兼容迁移。

当前步骤：

    新增 server 侧 workspace DTO 校验模块。
    WorkspaceFileStore 读写前调用 DTO 校验。
    补齐文件仓库和 API 回归测试。
    验证通过后停下审核。

完成标准：

    manifest schema 外字段、缺失字段、错误类型被拒绝。
    重复 note id、重复 tree id、未知 note 引用被拒绝。
    manifest 指向缺失 note 文件时报错。
    非法 PUT /api/workspace 不覆盖已有 workspace。
