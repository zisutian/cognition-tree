3. 近期实施顺序

3.1 解析器结构能力

目标：

    为块迁移和结构视图提供可靠范围信息。

步骤：

    增加 fenced code block 解析。
    增加行内结构 inlineSpans。
    增加块子树结束行信息 endLineNumber。
    保证代码块内部不解析 marker 和行内结构。

3.2 跨笔记块迁移底座

目标：

    支持不同笔记之间移动整棵块子树。

步骤：

    抽出块文本纯函数。
    增加 syntaxImports 数据模型。
    实现有效语法解析。
    实现跨笔记移动整棵块子树。
    实现缺失语法块引用随迁提示。

3.3 块迁移 UI

目标：

    先验证流程，再接入拖拽。

步骤：

    增加双笔记结构面板。
    先做点击式“从左移到右”。
    再在同一套移动 API 上接入拖拽交互。

3.4 Docker 打包与部署验证

目标：

    将已经稳定的 HTTP 后端容器化，并验证 Docker volume 持久化。

步骤：

    增加 Dockerfile。
    增加 compose 文件。
    明确 volume 数据目录。
    验证容器重启后数据保留。
