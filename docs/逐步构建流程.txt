逐步构建流程


文档职责：

    记录当前工程状态、当前主线、近期执行顺序、验证命令和暂缓事项。
    不记录产品原则、详细需求、长期架构和个人环境。


1. 当前状态

当前分支：

    web-docker-runtime

当前路线：

    浏览器前端 + 本机 Node HTTP 后端 + 本地文件仓库。
    桌面运行实现已从当前分支剔除。
    Docker 容器化后移为独立阶段。

已完成主线：

    HTTP 存储闭环。
    默认 CTN 语法和解析器结构能力。
    CTN parser 与 CSS 拆分。
    独立 syntax/*.toml 语法文件。
    仓库级语法文件新增、编辑、删除和笔记级语法选择。
    语法 profile 表达能力增强。
    显式跨笔记块迁移闭环。
    语法界面和迁移界面分化。
    Workspace 应用层初步拆分。
    源码层级整理为 app / features / shell / workspace / domain / ctn / syntax / storage。

当前未提交工作：

    Workspace 架构重构。
    docs 文档体系重构。
    持久化链路命名从早期 note-only 语义调整为 WorkspaceRepository / WorkspaceFileStore / workspaceApiServer。
