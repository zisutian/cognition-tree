# 快速入门

要求 Node.js 22.18.0 或更高版本、pnpm 11.1.3 与 Git。模型服务是可选项。

在项目根运行：

    ./start.sh

打开 `http://127.0.0.1:3001`。首次运行会安装锁定依赖并接入已有提交钩子。

1. 从左侧活动栏进入“仓库”，使用本地分组的 `+` 创建普通笔记库。
2. 在主区点击“继续编辑笔记”，从笔记目录创建笔记或文件夹，直接编辑正文。
3. 日记和代办是独立的全局内容。日记按日期组织条目，代办按集合组织任务。
4. 在“语法”调整当前领域的规则；底栏问题可展开并定位到需要处理的内容。

正文自动保存。发生同步冲突后可以继续编辑，剩余冲突在仓库恢复区域处理；
所有冲突消除后自动恢复同步。不要用刷新网页代替保存，未同步的页面草稿不会跨刷新恢复。

配置和认证步骤见[设置操作](settings.md)；生产构建、容器持久化、服务公开与迁移恢复见
[部署与恢复](deployment.md)。外部工具见[API 与 CLI 集成](api-integration.md)，
开发验证见[测试指南](testing.md)。
