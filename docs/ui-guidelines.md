# 界面规范

通用视觉与交互使用 Compact UI 0.1.0 的公开组件和默认配置。认知树仅拥有业务内容及其投影；模块边界见 [架构说明](architecture.md)。

## 组件与样式

安装包固定在 `tooling/vendor/compact-ui-0.1.0.tgz`，通过相对文件依赖安装。不能依赖本机兄弟目录，不能导入包的私有目录或覆盖内部类名。根部 `CompactProvider` 使用 [uiConfig](../presentation/ui/foundation/config.ts)，公开 `compact-ui/styles.css` 仅在客户端入口加载一次。

按钮、字段、表单、分组、静态属性、管理列表、状态及浮层直接使用包公开组件。工作台用 `Workbench` 和 `WorkbenchLayoutState`；活动提供 title、content、actions、toolbar、footer 和 layout，不再自行绘制分区外壳。

编辑器、CTN 结构块、图谱和差异正文保留专用内容实现。内容样式只读取 `--cu-*` 变量，不重新声明通用参数。CTN 语义颜色保持独立；没有第二套通用主题、尺寸生成器或拖动分区实现。

目录统一使用包内 `Tree`。业务层映射稳定节点、受控展开/选择和命令；重命名、删除确认、键盘操作、拖放提示和弹出菜单的通用交互由包负责。CTN 富文本结构树保留多行选择和结构拖放内容语义。

## 页面导航

[PageNavigation](../presentation/navigation/index.ts) 唯一拥有打开、激活、固定、关闭和页面会话。目标由 activityId、kind、repositoryId、id 组成，重命名只更新标签文字。

- 左侧单击打开预览，双击固定；打开活动会展开对应目录。
- 全工作台只有一个临时预览。已固定目标再次打开仍为固定目标。
- 中栏 `ChoiceGroup` 只激活和关闭，不改变目录折叠状态。
- 笔记、结构操作、引用图谱以及仓库语法按仓库隔离固定页；日记、待办、会话、搜索和管理页跨仓库保留。
- 查看仓库管理对象不切换真实仓库。实际切换先完成应用层保存检查，成功后恢复目标仓库页面。
- 新建成功后固定打开；搜索、引用、问题定位进入预览并复用既有目标。
- 删除确认后裁剪相关页；尚在载入的资源不能被当作已删除。关闭活动页由相邻标签接替，最后一页关闭后显示空工作区并接收焦点。

业务内容与保存状态仍由应用控制器持有。设置草稿与无效语法继续阻止离开；未解决保存状态的预览保留为固定页。关闭正文页先完成原有同步检查，失败保留页面和恢复入口。异步导航使用代次判断，迟到结果不能提交新标签状态。

## 生命周期与布局

页面标签和视图状态仅存在于本次登录会话。刷新、退出登录后清理；删除仓库时一起裁剪。编辑器按完整页面标识保存 CodeMirror 状态、光标和滚动，激活时重新绑定回调并与应用权威正文同步；不同文档不能共享撤销栈。编辑器任务复选框由 React 适配桥使用公开 `CheckboxControl`。

编辑器、目录、图谱等内容拥有内部滚动并使用 `fill`。普通表单和详情使用包布局。会话消息和输入分离，输入、审批及设置保存按钮位于工作台区域 footer，正文滚动不带走固定操作。不得增加第二层面板外壳或覆盖包的滚动条。

通用尺寸、颜色和键盘交互以固定包的默认规则为准；测试不继续断言旧 UI 的尺寸。使用合成数据覆盖 1280×720、1440×900、缩放、窄分区、长标题、焦点恢复、弹层和独立滚动。业务测试保留保存、同步、审批和破坏性确认断言。

设置表单通过显式 `fixedPageActions` 区域选项把本地状态驱动的按钮渲染到 footer 的 DOM 入口；页面仍独占草稿和提交回调，Shell 不保存第二份表单操作状态。搜索结果与问题列表分别直接使用 ManagementList/ManagementRow 和 ContextList/ContextRow。问题列表的长集合只在自身内容容器维护虚拟占位。
