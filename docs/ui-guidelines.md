# 界面规范

通用视觉与交互使用 Compact UI 0.3.1 的公开组件和默认配置。认知树仅拥有业务内容及其投影；模块边界见 [架构说明](architecture.md)。

## 组件与样式

安装包固定在 `tooling/vendor/compact-ui-0.3.1.tgz`，通过相对文件依赖安装。不能依赖本机兄弟目录，不能导入包的私有目录或覆盖内部类名。根部 `CompactProvider` 使用 [uiConfig](../presentation/ui/foundation/config.ts)，公开 `compact-ui/styles.css` 仅在客户端入口加载一次。

优先按功能查找包内组件，再决定是否需要业务组合；仅替换按钮并保留自绘通用布局不算接入完成。按钮、字段、表单、分组、静态属性、管理列表、状态及浮层直接使用包公开组件。工作台用 `Workbench` 和 `WorkbenchLayoutState`；活动提供 title、content、actions、toolbar、footer 和 layout，不再自行绘制分区外壳。

工具栏图标、笔记工具切换、复制、普通刷新、取消和问题计数使用公开 `appearance="plain"`，保留悬停、焦点与选中反馈；保存、创建提交、恢复及危险确认保留默认背景。不得通过 CSS 取消按钮反馈。

编辑器、CTN 结构块、图谱和差异正文保留专用内容实现。内容样式只读取 `--cu-*` 变量，不重新声明通用参数。编辑器字号和行距也直接读取框架默认值，不增加编辑器外框。语法规则使用公开 `List columns={6}` 和 `Stack` 排成单行，块规则与行内规则分别只显示一组列名；名称、标记、角色、颜色和操作使用固定列位，受保护或不适用字段保留空位以避免错列。只有独立的缩进字段使用 `FieldRow`、`FormLayout`，颜色选择直接使用 `ColorPicker sizing="fill"`，收起时显示色块和名称／自定义色值，弹层、色板、输入与焦点恢复均由包提供。适配器从既有 CTN 内容变量读取预设颜色，并映射回原有语法标识；不透明 CSS 自定义颜色转为既有六位十六进制存储，取消不修改语法。新增规则操作放在对应 Section 的标题操作区。通用色块样式已删除；右侧预览只拥有 CTN 内容样式。`syntaxPalette.css` 保留已有语法命名色的含义，不能被其它 UI 用作主题。无效草稿恢复操作位于区域 footer，离开检查仍由活动公开接口提供。没有第二套通用主题、尺寸生成器或拖动分区实现。

CodeMirror 使用光标、文字选区及当前行提供编辑反馈。编辑器适配层同时处理 `.cm-editor` 与真正获得焦点的 `.cm-content`，避免框架的通用 `:focus-visible` 给整个滚动正文画出大外框。此规则只作用于编辑器自身，不移除按钮、字段、目录等普通控件的键盘焦点提示。

左栏“编辑／结构／图谱”是工具操作，使用区域 toolbar 内横向的公开 `Button`，通过 `aria-pressed` 表示当前工具，Tab 移动焦点、Enter/空格打开，单击预览、双击固定。不能为了复用打开事件将其伪装成目录树。

真正的目录统一使用包内 `Tree`。业务层映射稳定节点、受控展开/选择和命令；重命名、删除确认、键盘操作、拖放提示和弹出菜单的通用交互由包负责。CTN 富文本结构树保留多行选择和结构拖放内容语义。

## 页面导航

[PageNavigation](../presentation/navigation/index.ts) 唯一拥有打开、激活、固定、关闭和页面会话。目标由 activityId、kind、repositoryId、id 组成，重命名只更新标签文字。

- 左侧单击打开预览，双击固定；打开活动会展开对应目录。
- 目录收起时不保留单独的展开栏，由最左侧活动入口恢复。状态栏只保留错误／警告按钮开关问题面板，不再并列展开箭头；面板内关闭后焦点回到该按钮。
- 全工作台只有一个临时预览。已固定目标再次打开仍为固定目标。
- 中栏 `PageTitleGroup` 只激活和关闭，不改变目录折叠状态。
- 工作台所有页面保留右栏，包括无详情、活动载入中及关闭全部标签后的空工作区。活动没有详情时由 Shell 提供标题和正文均为空的分区，不显示空内容提示。手动收起及专注模式仍遵循原有工作台操作。
- 笔记、结构操作、引用图谱以及仓库语法按仓库隔离固定页；日记、待办、会话、搜索和管理页跨仓库保留。
- 查看仓库管理对象不切换真实仓库。实际切换先完成应用层保存检查，成功后恢复目标仓库页面。
- 当前仓库不提供“继续编辑笔记”按钮，返回笔记使用活动入口；其它仓库保留“打开仓库”。
- 新建成功后固定打开；搜索、引用、问题定位进入预览并复用既有目标。
- 删除确认后裁剪相关页；尚在载入的资源不能被当作已删除。关闭活动页由相邻标签接替，最后一页关闭后显示空工作区并接收焦点。

业务内容与保存状态仍由应用控制器持有。设置草稿与无效语法继续阻止离开；未解决保存状态的预览保留为固定页。关闭正文页先完成原有同步检查，失败保留页面和恢复入口。异步导航使用代次判断，迟到结果不能提交新标签状态。活动加载占位在加载完成后原位转换，即使已经固定也不能留下重复标签。异步创建必须在发起时通过 `prepareOpen` 捕获导航请求版本；创建返回可以更新目录，但用户已经导航到其它页面时不能自动抢回焦点。较新的选择被拒绝时仍需清理 pending。

## 生命周期与布局

页面标签和视图状态仅存在于本次登录会话。刷新、退出登录后清理；删除仓库时一起裁剪。编辑器按完整页面标识保存 CodeMirror 状态、光标和滚动，激活时重新绑定回调并与应用权威正文同步；不同文档不能共享撤销栈。关闭页面和退出登录先撤销会话写入资格，之后的卸载回调不能复活旧状态；关闭后重开使用新的撤销会话。不得为了保留状态在工具页背后隐藏挂载编辑器。编辑器任务复选框由 React 适配桥使用公开 `CheckboxControl`。

编辑器、目录、图谱等内容拥有内部滚动并使用 `fill`。普通表单使用 `FormLayout` 默认 columns 排布，在窄容器下由框架自动转为纵向；不再统一强制 stacked。搜索提交按钮与输入框使用包内行布局组合。详情使用包布局。会话消息和输入分离，输入、审批及设置保存按钮位于工作台区域 footer，正文滚动不带走固定操作。不得增加第二层面板外壳或覆盖包的滚动条。

通用尺寸、颜色和键盘交互以固定包的默认规则为准；测试不继续断言旧 UI 的尺寸。使用合成数据覆盖 1280×720、1440×900、缩放、窄分区、长标题、焦点恢复、弹层和独立滚动。业务测试保留保存、同步、审批和破坏性确认断言。

设置表单通过显式 `fixedPageActions` 区域选项把本地状态驱动的按钮渲染到 footer 的 DOM 入口；页面仍独占草稿和提交回调，Shell 不保存第二份表单操作状态。搜索结果与问题列表分别直接使用 List/ManagementRow 和 List/ContextRow。问题列表的长集合只在自身内容容器维护虚拟占位。

问题面板只提供一组 `ChoiceGroup` 筛选按钮，顺序为“全部、警告、错误”，默认选择全部；不再提供来源和可重试性筛选。收起后重新打开保留本次会话的筛选选择，问题行仍保留定位信息与已有恢复入口。

额外错误说明只出现在输入框内部或底部问题区。字段校验使用公开控件的 `error`，其他当前失败由原有问题中心或源状态投影到底栏；正文、目录与详情只保留状态、重试和恢复操作。登录页没有工作台，错误放在页底固定位置，不挤动表单。危险操作按钮、差异删除行和编辑器内部诊断保留原有语义颜色。

## 组件优先与必要适配

| 功能                                 | 公开组件或保留理由                                                                                                                      |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| 页面间距、操作栏、固定操作           | Stack、Toolbar、FormActions；Page 仅保留语义、引用、滚动和 footer 接线                                                                  |
| 普通表单与语法规则                   | FormLayout、FieldRow、公开输入控件；语法每条规则使用 List 的固定六列，共享列名；不重复渲染字段表单                                      |
| 文档统计、图谱统计、时间             | PropertyList / PropertyRow；时间值保留 time 的机器可读日期                                                                              |
| Agent 消息、资源审查、引用、搜索结果 | List / ManagementRow；消息换行、代码和差异正文属于内容                                                                                  |
| 目录、颜色预设、筛选                 | Tree、ChoiceGroup、CheckboxGroup；不以 label 包裹整个选择组，避免覆盖首项名称                                                           |
| 登录、空状态、提示、浮层             | Panel、EmptyState、StatusText、Popover / QuickPick；StatusText 的 live 仅表示视觉状态，需要播报时由语义宿主提供 role                    |
| 外置保存按钮的设置表单               | AssociatedForm 只把标准 DOM id 关联到公开 FormLayout 生成的 form；footer 仍使用原生提交关联，保留必填/范围校验和 Enter 提交，无嵌套表单 |
| 错误提示                             | 字段错误使用公开输入控件的 error；其他错误进入工作台底栏，登录错误进入登录页底部；不在正文或详情重复显示                    |
| 技术详情折叠                         | 包没有通用 Disclosure，保留原生 details/summary；内容由公开 Section、属性和列表组件组织                                                 |
| CTN 编辑与结构、图谱、差异           | 包没有对应业务编辑内核；独立内容适配保留富文本、选择、任务、拖放、画布和差异语义                                                        |

新增通用组件或样式前必须记录对应包能力缺口。禁止重复实现列表、字段排版、颜色选项网格或控件交互；删除替换后无消费者的样式。组件默认阅读宽度属于包规则，不能为了满足旧尺寸断言覆写。
