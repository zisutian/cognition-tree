# 界面规范

本文件说明认知树的页面、交互与状态呈现契约。通用控件和视觉使用 Compact UI 的公开能力；
依赖版本由[package.json](../package.json)及锁文件确定，模块分工见[模块边界](architecture.md)。

## 组件与样式

Compact UI 通过仓库内固定安装归档接入，不依赖本机兄弟目录。`CompactProvider` 使用
[uiConfig](../presentation/ui/foundation/config.ts)，公开样式在客户端入口加载一次。
认知树只补充视口几何与 CTN 内容配色，不覆写包的私有类名、通用参数或控件交互。

工作台分区、目录、普通列表、表单、颜色选择、状态与浮层直接使用公开组件。
编辑器、CTN 富文本结构、图谱和差异正文保留业务适配，内容样式读取框架配置。
新增适配需要能说明业务语义或包能力缺口，替换后移除无消费者的通用实现。

普通工具操作采用弱背景样式，保留悬停、焦点与选中反馈；保存、创建、恢复及危险确认保留
明确按钮背景。编辑器用光标、选区和当前行反馈焦点，不给整块滚动正文绘制外框；
这不影响普通控件的键盘焦点提示。

### 语法编辑

每条语法规则按固定六列单行排列，块规则和行内规则各有一组共享列名，受保护或不适用字段保留列位。
缩进作为独立表单字段，颜色选择使用包组件并映射已有 CTN 色值；取消不修改草稿。
新增操作位于对应规则组标题区，无效草稿的恢复操作位于区域底部。
右侧预览消费同一草稿，保存后的解析与颜色语义见[CTN 分析流水线](ctn-analysis-pipeline.md)。

### 目录与内容树

普通资源目录使用 `Tree`，业务提供稳定节点、选择、展开和命令。共享 CTN 结构适配使用
`ContentTree`，提供稳定块 ID、正文与行内格式、类型名称、行号和诊断汇总；键盘、焦点、
虚拟化及通用拖放由框架提供。代办结构另外保留任务勾选与周期编辑。

结构树的业务契约是：

- 首次展开全部；切换文档重置，同一文档更新保留仍有效的展开状态，新分支默认展开。
- 树根为唯一 Tab 入口，活动焦点与业务选中独立；外部选择只展开祖先并定位一次，不抢编辑器焦点。
- 笔记和日记阅读树单选，结构操作树选择完整子树，跨笔记目标树不声明选择。选中底色逐行表达，折叠不改变业务选择范围。
- 父行点击同时选择并切换展开；右键、菜单键及 Shift+F10 进入同一结构菜单。
- 类型标签使用工作台共享、可持久化偏好；隐藏只影响显示，不清除语法、行号或诊断，不保存文档。
- 结构移动以稳定块 ID 定位当前内容；许可检查无副作用，提交结果与失败反馈由业务处理。

设置目录按用途展示叶项图标，分组使用框架箭头；Provider/Profile 的新建入口分别位于各组首项。
图标不改变可访问名称、选择语义或草稿保护。

## 页面导航

[PageNavigation](../presentation/navigation/index.ts) 拥有打开、激活、固定、关闭与页面会话。
页面用活动、类型、仓库与对象稳定 ID 标识；重命名只改变标签，不改变身份。

- 左侧单击预览、双击固定，全工作台只有一个临时预览；已固定目标再次打开仍保持固定。
- 新建成功后固定打开，搜索、引用和问题定位进入预览并复用既有目标。
- 内容创建从左栏开始；中栏空状态不重复提供创建入口。代办集合表单位于左栏创建入口下方。
- “编辑／结构／图谱”为横向工具按钮，用按下状态表达当前工具，不伪装为目录节点。
- 查看仓库管理对象不切换实际仓库；其他仓库可“打开仓库”，当前仓库通过笔记活动返回内容。
- 关闭活动页后激活相邻页；最后一页关闭显示空工作区并接收焦点。载入中的资源不能视为已删除。
- 笔记、结构、图谱和仓库语法页面按仓库隔离；日记、代办、会话、搜索与管理页跨仓库保留。

导航先完成离开检查和目标选择，再提交页面状态。设置草稿、无效语法和未完成保存阻止离开时，
保留页面及恢复入口，被阻止的导航不排队。预览有未解决保存状态时保留为固定页。
异步导航和新建结果只对仍有效的请求生效，迟到创建可更新目录但不能抢回页面；
加载占位原位转为真实目标，不能产生重复标签或遗留 pending。

专注模式保留 `Ctrl/Cmd+K`、`Z` 组合键。Escape 先由顶层浮层、编辑器或局部控件处理，
未被消费时才退出专注模式；输入法组合输入和组合键取消不触发退出。

## 生命周期与布局

### 页面状态

页面标签和编辑器视图仅保留于当前登录会话，刷新或退出登录后清理，删除仓库时裁剪对应分区。
编辑器按完整页面身份保留撤销、光标和滚动；激活先绑定当前回调，再同步应用权威正文。
关闭或删除页面后，卸载回调不能恢复旧快照；重开建立新撤销会话，不用隐藏编辑器保留后台状态。
可持久化偏好的清单见[服务运行](service-runtime.md#状态与存储)。

设置草稿由对应对象会话持有基线版本、编辑代次和提交状态；响应只更新对应会话，旧回执不能
清除新输入。配置已提交但状态刷新失败时，区分两种结果，保留已提交事实。secret 随表单卸载清除，
服务端 pending 操作不因页面卸载自动取消。设置操作及离开保护见[设置操作](settings.md#选择与保存)。

### 工作台布局

活动声明各区标题、内容、工具栏、固定操作和布局，由 shell 适配到包的工作台。
所有页面保留右栏，包括载入和空工作区；无详情时标题和正文均为空。用户仍可收起右栏或进入专注模式。
目录收起后从活动入口恢复；中栏页面标签不改变目录折叠状态。

编辑器、目录和图谱独立滚动。普通表单使用框架默认列布局，窄容器自动纵向排列；
会话输入、审批和设置保存操作固定在区域底部，不随正文滚动。
普通列表根据内容密度使用包的布局，业务继续控制选择和独立操作，不另造面板外壳或滚动条。

### 问题与反馈

底栏统一展示领域诊断、状态故障和聚合操作错误。筛选按“全部、警告、错误”排列，默认全部；
收起再打开保留本次会话选择。来源与恢复信息仍显示在问题中，不另设筛选条件。
关闭面板后焦点回到状态栏的问题按钮。

字段校验显示在输入控件内部，其他当前错误进入底部问题区；正文与详情保留状态和恢复操作，
不重复错误段落。登录页没有工作台，错误固定在页底。危险操作、差异删除和编辑器诊断保留语义颜色。
状态故障随源状态恢复自动消失；操作错误可关闭。稳定保存不提示成功，短暂反馈由问题中心统一调度。
问题定位只导航，不自动重试或执行修改。单个 Activity 的加载或渲染失败由页面错误边界隔离，
其他活动及工作台继续可用。

## 组件优先与必要适配

| 业务内容 | 使用方式 |
|---|---|
| 工作台、间距、工具栏和固定操作 | 公开 Workbench、Stack、Toolbar、FormActions |
| 普通表单、静态属性、列表 | FormLayout、FieldRow、PropertyList、List/ListRow |
| 目录、CTN 阅读树、颜色与筛选 | Tree、ContentTree、ColorPicker、ChoiceGroup 等公开组件 |
| 编辑器任务控件 | React bridge 连接公开 CheckboxControl，不引用私有样式 |
| 区域底部的表单提交 | AssociatedForm 仅关联原生 form id，保留校验和 Enter 提交，不另存表单状态 |
| 技术详情 | 原生 details/summary 配合公开内容布局 |
| CTN 编辑、图谱和差异正文 | 保留业务内核，通用布局和控件仍由框架提供 |

颜色、几何、焦点及窄分区验证见[测试指南](testing.md#针对性验证)。业务回归保留保存、同步、
审批与危险确认，不用旧组件尺寸约束新的框架默认值。
