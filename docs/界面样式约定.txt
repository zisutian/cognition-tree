界面样式约定


文档职责：

    记录界面主题、字体、字号、字重、边框和状态色约定。
    不记录具体功能需求、组件实现细节和当前任务计划。


1. 总原则

界面主题以 VS Code 默认暗色主题为基准。

样式优先级：

    先定义全局主题 token。
    组件只消费 token，不自行发明颜色系统。
    只有语法高亮、图谱节点和错误状态可以使用语义颜色。

暗色界面原则：

    大面积背景使用中性深灰。
    侧栏、活动栏、编辑器和详情面板必须有稳定层级差。
    边框只用于区域分隔、输入框和明确交互边界。
    不使用黄绿、黄褐、暖灰作为暗色主色。
    不使用大面积高饱和色块。
    选中态使用 VS Code 蓝或列表选中灰蓝。


2. 颜色约定

基础色：

    活动栏背景：#333333
    侧栏背景：#252526
    编辑器背景：#1e1e1e
    面板抬升背景：#252526
    悬停背景：#2a2d2e
    列表选中背景：#37373d
    分隔线：#2d2d30
    控件边框：#3c3c3c

文字：

    主文字：#cccccc
    弱文字：#969696
    次弱文字：#6f6f6f
    强文字：#ffffff

文字使用规则：

    正文、列表项、结构树内容使用主文字。
    页面标题、重要当前项和需要读取优先级最高的内容使用强文字。
    统计、路径、辅助说明、禁用前的弱提示使用弱文字。
    极弱信息、占位文本和不可用信息使用次弱文字或禁用文字。
    语法颜色不直接改变正文颜色；行首语法主要改变弱背景，行内语法主要改变下划线颜色。
    组件样式不得直接写新的字体颜色，应优先使用 theme token。

强调色：

    主强调蓝：#007acc
    按钮蓝：#0e639c
    按钮悬停蓝：#1177bb
    文本链接蓝：#569cd6

状态色：

    错误：#f48771
    警告：#cca700
    成功：#6a9955

语法色：

    语法高亮只能作为弱背景或下划线提示。
    整行背景透明度必须低，避免盖过正文。
    行内结构使用下划线，不使用实心色块。
    预设色使用适合暗色模式的 VS Code-ish 色系：green、teal、cyan、blue、indigo、violet、pink、red、amber、gray。
    代码不是独立颜色；代码块和行内代码默认使用 green。


3. 字体约定

当前统一字体：

    Noto Sans CJK SC

用途：

    UI、正文、代码和语法符号暂时全部使用同一中文字体。
    后续如引入等宽字体，必须单独评估中文、英文、符号和缩进对齐效果。


4. 字号约定

根字号：

    14px

层级：

    页面标题：20px
    区域标题：18px
    卡片标题：16px
    正文和编辑器：14px
    表单、列表和普通控件：12px
    辅助信息和统计：11px

原则：

    不按视口宽度缩放字号。
    紧凑面板内不使用大标题。
    侧栏列表、结构树和迁移列表保持 12px 级别。


5. 字重约定

常规文本：

    400

列表项和正文内容：

    400 或 500

按钮、字段标签和结构类型：

    600

页面标题和重要节点：

    700

原则：

    不用加粗补偿颜色层级。
    同一类信息必须保持一致字重。


6. 控件约定

按钮：

    主按钮使用 VS Code 按钮蓝。
    次按钮使用透明或面板背景，只保留细边框。
    图标按钮不使用实心背景，悬停时显示列表 hover 背景。

输入框：

    背景使用 #3c3c3c 或面板抬升背景。
    边框使用 #3c3c3c。
    聚焦只显示蓝色边框，不叠加强烈阴影。

列表：

    hover 使用 #2a2d2e。
    selected 使用 #37373d。
    不使用大面积彩色选中块。

边框：

    只保留必要分隔。
    卡片式容器必须减少，避免界面变成多个框套框。


7. 文档关系

本文件约束界面表现。

    产品需求只描述用户想达到的界面目标。
    工程架构只描述样式目录和组件职责。
    逐步构建流程只记录当前是否正在执行主题整理。
