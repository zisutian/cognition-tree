界面样式约定


文档职责：

    只记录稳定 UI 视觉约定和样式 token。
    不记录功能需求、组件实现细节、当前任务和工程分层。


1. 主题

基准：

    VS Code 默认暗色主题。

原则：

    大面积背景使用中性深灰。
    侧栏、活动栏、编辑器和详情面板必须有稳定层级差。
    组件优先消费全局 token，不自行发明颜色系统。
    只有语法高亮、图谱节点和错误状态可以使用语义颜色。
    不使用大面积高饱和色块。


2. 颜色

基础色：

    活动栏背景：#333333
    侧栏背景：#252526
    编辑器背景：#1e1e1e
    面板背景：#252526
    悬停背景：#2a2d2e
    列表选中背景：#37373d
    分隔线：#2d2d30
    控件边框：#3c3c3c

文字：

    主文字：#cccccc
    弱文字：#969696
    次弱文字：#6f6f6f
    强文字：#ffffff

强调与状态：

    主强调蓝：#007acc
    按钮蓝：#0e639c
    按钮悬停蓝：#1177bb
    文本链接蓝：#569cd6
    错误：#f48771
    警告：#cca700
    成功：#6a9955


3. 字体与字号

字体：

    Noto Sans CJK SC

字号：

    页面标题：20px
    区域标题：18px
    卡片标题：16px
    正文和编辑器：14px
    表单、列表和普通控件：12px
    辅助信息和统计：11px

原则：

    不按视口宽度缩放字号。
    紧凑面板内不使用大标题。
    同一类信息保持一致字重。


4. 控件

按钮：

    主按钮使用 VS Code 按钮蓝。
    次按钮使用透明或面板背景，只保留细边框。
    图标按钮不使用实心背景，悬停时显示 hover 背景。

输入框：

    背景使用 #3c3c3c 或面板背景。
    聚焦只显示蓝色边框，不叠加强烈阴影。

列表：

    hover 使用 #2a2d2e。
    selected 使用 #37373d。
    可滚动列表默认隐藏原生滚动条，但保留滚轮、触控板和键盘滚动。
    正文编辑器不套用列表滚动条规则。


5. 语法色

    tone 只作为弱背景或下划线提示。
    textColor 负责字体颜色，视觉优先级高于 tone。
    整行背景透明度必须低。
    行内结构使用下划线，不使用实心色块。
    预设色为 green、teal、cyan、blue、indigo、violet、pink、red、amber、gray。
