界面样式约定


1. 主题

界面基准是 VS Code 默认暗色主题。

大面积背景使用中性深灰。侧栏、活动栏、编辑器和详情面板具有稳定层级差。

组件颜色来自全局 token。语法高亮、图谱节点和错误状态使用语义颜色。


2. 颜色

基础色：

    活动栏背景：#333333
    侧栏背景：#252526
    编辑器背景：#1e1e1e
    面板背景：#252526
    悬停背景：#2a2d2e
    列表选中背景：#37373d
    分隔线：#2d2d30
    控件边框：#3c3c3c

文字：

    主文字：#cccccc
    弱文字：#969696
    次弱文字：#6f6f6f
    强文字：#ffffff

强调与状态：

    主强调蓝：#007acc
    按钮蓝：#0e639c
    按钮悬停蓝：#1177bb
    文本链接蓝：#569cd6
    错误：#f48771
    警告：#cca700
    成功：#6a9955


3. 字体与字号

字体：

    Noto Sans CJK SC

字号：

    页面标题：20px
    区域标题：18px
    卡片标题：16px
    正文和编辑器：14px
    表单、列表和普通控件：12px
    辅助信息和统计：11px

字号特征：

    字号不随视口宽度缩放。
    紧凑面板使用小标题。
    同一类信息使用一致字重。


4. 控件和列表

按钮：

    主按钮使用 VS Code 按钮蓝。
    次按钮使用透明或面板背景，只保留细边框。
    图标按钮使用透明背景，悬停时显示 hover 背景。

输入框：

    背景使用 #3c3c3c 或面板背景。
    聚焦状态显示蓝色边框。

列表：

    hover 使用 #2a2d2e。
    selected 使用 #37373d。
    同类树形列表具有统一缩进、行高、hover 和 selected 表现。
    可滚动列表默认隐藏原生滚动条，同时保留滚轮、触控板和键盘滚动。
    正文编辑器使用独立滚动样式。


5. 语法色

    tone 表现为弱背景或下划线提示。
    textColor 负责字体颜色，视觉优先级高于 tone。
    整行背景透明度低。
    行内结构使用下划线。
    预设色为 green、teal、cyan、blue、indigo、violet、pink、red、amber、gray。
