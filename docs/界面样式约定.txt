界面样式约定


1. 基准

界面基准是 VS Code 默认暗色主题。整体表现接近编辑器工具，保持平面、克制、高信息密度和低装饰。

界面由活动栏、上下文区、主工作区和详情区组成。上下文区按页面需要出现；没有目录、筛选或对象入口的页面不显示上下文区。

笔记界面和结构操作界面是结构样本。笔记代表文档编辑型页面，结构操作代表笔记结构操作型页面。其他页面按自身任务选择槽位，不继承目录布局。


2. 页面类型

文档编辑型页面使用上下文区、主工作区和详情区。上下文区显示文档目录，主工作区显示正文编辑，详情区显示结构、统计和诊断。

结构操作型页面使用上下文区和全宽主工作区。上下文区显示对象入口，主工作区承载结构选择、拖放目标和操作反馈。

配置表单型页面使用主工作区和详情区。主工作区显示可编辑配置，详情区显示当前状态、统计和问题。

图谱查看型页面使用主工作区和详情区。主工作区显示画布和筛选控件，详情区显示选中对象、关系和问题。

检索、数据和设置页面以主工作区为主体，不强制显示上下文区。


3. 尺度

活动栏宽度 48px。折叠详情宽度 36px。主工作区最小可用宽度 420px。

面板标题高度 32px 到 34px。面板内边距 8px 到 10px。主要间距 6px。紧凑间距 4px。

树行高度 20px 到 22px。输入框和按钮高度 22px 到 24px。图标按钮宽高 22px 到 24px。边界宽度 1px。

标题字体 16px / 600。正文、列表和树字体 13px / 400。辅助文字和元信息 12px / 400。编辑器正文 14px。

常规圆角 3px 到 4px。阴影用于菜单、tooltip 和浮层。常规列表、表单、状态区域和面板保持无卡片外框。


4. 颜色

活动栏背景 #333333。上下文区和面板背景 #252526。主编辑背景 #1e1e1e。

hover 背景 #2a2d2e。selected 背景 #37373d。普通边界 #2d2d30。强边界和输入背景 #3c3c3c。

普通文字 #cccccc。强文字 #ffffff。弱文字 #969696。主 accent #007acc。主按钮 #0e639c。错误 #f48771。成功 #6a9955。

语法 tone 使用弱背景、下划线和文字色表达。整行背景保持低透明度。


5. 共享结构

树结构用于笔记目录、笔记结构、迁移目录和迁移块结构。缩进表达层级，hover 表示指向，selected 表示当前对象，accent 表示操作焦点或拖放目标。

不同树的业务差异通过行内标记、操作按钮、拖放状态和选择状态表达。相同交互语义使用相同视觉尺度。

页面标题、控件、列表、表单、状态、空状态和详情统计来自共享组件。活动页面只描述自身业务布局。
