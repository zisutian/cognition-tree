界面样式约定


1. 基准

界面基准是 VS Code 默认暗色主题。整体表现接近编辑器工具：平面、克制、高信息密度、低装饰。

workbench 由活动栏、上下文区、主工作区和详情区组成。活动栏始终存在。上下文区按页面需要出现。详情区按页面需要出现，并可折叠为窄入口。

笔记和结构操作是主要结构样本。笔记代表文档编辑型页面，结构操作代表结构整理型页面。其他页面按任务选择槽位，不继承目录布局。


2. 页面关系

笔记：

    上下文区显示笔记目录。
    主工作区显示可编辑内容，不显示块元数据保留行。
    详情区显示笔记统计、笔记时间、笔记结构和当前块时间；笔记时间不依赖结构选择，当前块时间跟随编辑光标和结构选择。

日记：

    上下文区使用不可编辑且可折叠的“年 → 月 → 日 → 条目”树；各层倒序，同日条目按创建时间、序号和稳定 ID 确定性倒序。进入活动时选择最新条目并展开其路径，新建和问题跳转也展开目标路径；折叠状态只在页面会话中保留。工具栏只提供手动新建入口，条目删除需要确认。
    主工作区标题显示不可修改的 `YYYY-MM-DD-0001` 当日序号标题，CodeMirror 只显示和编辑正文，不显示 synthetic title 或 canonical metadata。删除条目不复用序号。
    日记顶格无符号行使用中性的 `body` 正文语义，不显示普通笔记的概念强调，也不引入“概念簇”界面概念。
    详情区显示正文统计、条目时间、当前块时间和正文结构；正文结构行号从 1 开始，缩进仍可表达可选层级。
    `[[YYYY-MM-DD-0001]]` 选择并定位日记仓内条目；`[[仓库名:笔记名]]` 在解析完成后排空当前普通 session、切换命名仓库并进入笔记首行。加载期间不提前显示未解析，跨仓故障与歧义通过日记 Problems 呈现。

代办：

    上下文区以紧凑列表显示事项集合，提供新建、内联重命名、删除确认、拖动排序和键盘排序；选中集合决定主工作区内容。
    每个集合是一篇以集合名为标题的 CTN；主工作区只编辑正文，受保护的 `todo-item` 规则默认把 `[]` 渲染为可点击 checkbox，缩进表达父子任务。
    详情区显示同一份可勾选结构树；编辑器与结构树共享 completion sidecar，父子任务独立勾选且不级联。完成项保持原位置并划线，源码不改写为 `[x]`。
    块拖动和缩进只发生在当前集合并保留 block ID 与完成状态；集合自身仍可在上下文区拖动排序。代办活动挂载语法和 CTN Problems，并可定位 collection 与正文行。

结构操作：

    上下文区显示可选择的笔记入口。
    主工作区显示源笔记、目标笔记和笔记结构操作。
    详情区不显示。

仓库语法：

    上下文区分为“系统语法”和“笔记库语法”。系统组固定显示“日记”“代办”，允许选择编辑但不能新增、删除、重命名或切换版本；笔记库组显示当前普通仓库的有序语法文件。
    点击行只改变编辑目标，不改变普通仓库当前启用语法。选中的非活动文件显示行内“用”，活动文件显示“启用”；新建文件复制当前编辑文件并选中，但不自动启用。
    仓库和语法的行内按钮只在对应行被选中后渲染，不因 hover 或单纯 focus 出现。无效草稿存在时禁止离开当前语法或创建、删除其他语法，主工作区显示明确的“撤销无效更改”。
    主工作区显示当前 owner 的语法配置；日记使用中性 `body` 规则并保护引用规则，Todo 保护 `todo-item` 的语义 ID/role，但允许编辑名称、符号和颜色。
    详情区显示语法预览。

引用图谱：

    主工作区显示图谱画布和紧凑工具栏。
    详情区显示统计、当前节点、邻接关系和引用排名。
    上下文区不显示。

搜索和数据：

    主工作区承载页面内容。
    上下文区不显示。

仓库：

    上下文区使用与笔记目录一致的紧凑 master 列表，顺序固定为“内置数据”的日记、代办，“新建仓库”操作行，以及 Local、WebDAV、Browser 普通仓库分组。健康仓库和故障仓库在各自 adapter 分组中共同出现。
    行内只显示图标、名称和极简状态或问题标记。点击行只选中并刷新右侧详情；选中的非当前普通仓库显示行内“开”，当前仓库显示“当前”。“开”、重命名和其他行内按钮只在该行选中后显示，不因 hover 或单纯 focus 出现；切换后仍停留在仓库活动。
    主工作区是 detail，不显示独立详情栏。内容采用 VS Code 风格的平面高密度纵向结构，最大宽度约 720px；标题栏不承载添加、重扫、重试或危险操作。
    选中“新建仓库”时，右侧显示现有创建表单；创建成功后仍停留在仓库活动并显示新仓库详情。没有健康普通仓库时仍挂载完整工作台，普通内容活动显示前往仓库的入口。
    普通仓库详情显示名称、状态、adapter、保存状态和只读 ID。位置区按 adapter 显示结构化 location：Local 优先宿主机路径并补充服务端或容器内路径，WebDAV 显示无凭据 URL，Browser 显示 IndexedDB 数据库名。路径使用等宽字体、完整换行和可选择文本，每条路径提供复制操作。
    重扫、重试、清理、移除连接、停止跟踪和冲突恢复全部位于右侧操作区；“重新扫描文件”只表示显式读取，不暗示实时 watcher。删除托管数据与 WebDAV 删除远端数据位于页面末尾的 danger 区，并保持“仅移除连接”的不同语义与警告。
    选中的普通仓库行显示与笔记目录一致的小型重命名入口，并支持 F2 进入内联编辑；重命名入口不放在右侧。严格可移植名称、全局唯一键和“日记”“代办”保留名由存储边界拒绝。既有 `conflict`、`reserved` 或 `nonportable` label issue 保持可读，并在行状态、右侧详情和 Problems 中提示。
    日记和代办详情显示受保护状态、独立保存状态和结构化位置，不提供删除、重命名或切换为当前普通仓库的入口。不受支持的 Local snapshot 在右侧显示手工删除提示、可复制路径和重新检查入口，不发起自动清理请求。

设置：

    上下文区使用与其他活动一致的紧凑列表，当前只显示并选中“界面”。
    主工作区显示“界面”设置，当前只包含按仓库保存的左侧栏宽度。
    详情区和底部问题面板不显示。

全局问题面板：

    位于主工作区底部，不属于任何活动页面或详情区。
    普通活动显示普通 workspace 的笔记解析错误、活动语法配置错误和未解析引用。
    Repository 显示 workspace diagnostics、普通仓库问题、内置数据问题及 portable-name/label issue。问题行只选中并聚焦左侧对应条目，同时在右侧显示故障详情；破坏性操作不放入问题行。日记和代办的存储状态、位置、故障、重试与受保护说明只放在 Repository 的“内置数据”详情中。
    Journal 显示自身文档、内置语法、仓内引用和 `[[仓库名:笔记名]]` 跨仓引用诊断。Todo 显示自身内置语法、CTN 和缺少代办标记诊断。
    Syntax 显示当前编辑 owner 的 profile diagnostics；编辑活动笔记语法时附加普通 workspace diagnostics，编辑日记或代办语法时附加对应内容领域诊断。
    默认折叠；展开状态和高度按仓库保存。
    专注模式隐藏问题面板。
    Settings 完全不渲染问题面板，问题快捷键在该活动中不改变已保存的展开状态；Todo 正常挂载问题面板。


3. 尺度

    活动栏宽度：48px。
    详情折叠宽度：36px。
    主工作区最小宽度：420px。
    面板标题高度：32px 到 34px。
    面板内边距：8px 到 10px。
    主要间距：6px。
    紧凑间距：4px。
    树行高度：20px 到 22px。
    输入框和按钮高度：22px 到 24px。
    图标按钮宽高：22px 到 24px。
    常规圆角：3px 到 4px。
    分隔线：1px。
    问题面板折叠高度：24px。
    问题面板默认展开高度：200px。
    问题面板展开高度范围：120px 到 360px。
    问题行高度：22px。


4. 字体

    页面标题：16px / 600。
    正文、列表和树：13px / 400。
    控件和辅助文字：12px / 400 或 12px / 600。
    编辑器正文：14px。
    代码和符号：12px，使用等宽字体。
    数字：tabular-nums。

字号和字重通过角色 token 进入样式。activity 样式只描述页面布局和业务状态。


5. 颜色

    活动栏背景：#333333。
    上下文区背景：#252526。
    主编辑背景：#1e1e1e。
    面板背景：#252526。
    hover 背景：#2a2d2e。
    selected 背景：#37373d。
    普通边界：#2d2d30。
    强边界和输入背景：#3c3c3c。
    普通文字：#cccccc。
    强文字：#ffffff。
    弱文字：#969696。
    链接文字：#569cd6。
    主按钮背景：#0e639c。
    错误：#f48771。
    警告：#cca700。
    成功：#6a9955。

选中、聚焦和拖放状态以背景、文字和细边界表达。普通控件不使用亮色外框。诊断通过紧凑图标和行状态表达，不使用连续色条。


6. 共享结构

目录树：

    用于笔记目录和结构操作入口。
    前置区域使用 13px 符号槽。
    文件夹显示折叠符号和文件夹图标。
    笔记显示文档图标，业务状态可替换该图标。
    行操作位于右侧，只在 hover 或 selected 时显示。
    该 hover 行为只属于笔记目录；仓库和语法 context row 的小按钮必须在对应行 selected 后才渲染。

结构树：

    用于笔记结构、语法预览和结构操作中的块结构。
    前置 marker 是可变文本列，可以完整展示“组分”“理解”“定义”等名称。
    缩进按结构深度和当前缩进显示宽度计算，整行一起缩进。
    选中子树以整体背景表达。
    拖放落点按上方、下方和内部位置表达。

树容量：

    目录树和结构树保持固定 22px 行高。
    可见行不超过 500 时保留完整递归结构；超过 500 时使用窗口化渲染。
    窗口化只共享滚动和行高机制，目录行与结构行继续使用各自的数据、缩进和交互结构。

符号槽：

    用于目录树图标、引用图谱列表标记、工具按钮和紧凑状态。
    选中后符号颜色跟随文字转为强文字。

共享控件：

    Button、ToggleButton、SegmentedControl、Panel、Section、表单行、列表行和空状态由 shared primitives 提供。
    仓库、语法、日记和代办只共享紧凑 context list 的分组、行、选中态和内联编辑结构，各自保留独立 view model、命令和业务状态。
    二选一或多选项切换使用 SegmentedControl。
    表单控件使用背景态和文字态表达 hover、focus 和 selected。


7. 视觉约束

常规面板、列表、表单和状态区保持平面。阴影只用于菜单、tooltip 和浮层。

主工作区和详情区保持中等偏高的信息密度。标题只用于页面和面板层级，行内信息用 meta、符号、弱文字和紧凑间距表达。

页面之间保持槽位关系稳定。没有上下文内容的页面不渲染空上下文区；没有详情内容的页面不渲染空详情区。
