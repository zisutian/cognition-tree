界面样式约定


1. 基准

界面接近 VS Code 默认暗色主题：平面、克制、高信息密度、低装饰。Workbench 由活动栏、上下文区、主工作区、可选详情区和 Activity-scoped Problems 组成；没有内容的槽位不渲染占位。

笔记是文档编辑型页面样本，结构操作是结构整理型页面样本。其他页面只复用合适的视觉结构，不复用无关业务模型。


2. Activity 布局

笔记：

    上下文区显示目录；主区显示完整可编辑笔记；详情区显示统计、笔记时间、结构和当前块时间。
    canonical 标题行使用加粗字重，概念强调仍由语义类型独立决定。

日记：

    左侧是不可编辑的“年 → 月 → 条目”树，不显示“日”分类。进入时选择最新条目并展开年、月；新建和问题跳转同样展开目标路径。
    条目固定标题显示在面板标题中，CodeMirror 只编辑正文。选中条目后可在原行“删 → 确认/取消”，序号不复用。
    顶格无符号行是中性 body。详情区显示正文统计、条目时间、当前块时间和正文结构。

代办：

    左侧是可新建、内联重命名、删除和排序的事项集合，不显示分组或条目计数；集合整行使用共享列表拖拽及上方/下方落点，不显示专用拖拽按钮。主区只编辑所选集合正文；右侧显示同一 CTN 的任务结构。
    [] 渲染为 checkbox，缩进表示父子任务。完成项原位划线，不写回 [x]。
    右侧复用共享结构树的缩进、选中、诊断和行号样式，marker 位置只显示 checkbox；任务只允许勾选和定位，不提供拖动。

语法：

    左侧分“系统语法”和“笔记库语法”，两个分组都不显示计数。选中普通语法只打开编辑；行内“用”才改变启用项。当前启用项用固定前导状态图标替换文件图标，不在行尾重复“启用”文字。仓库与语法的小按钮只在该行 selected 后渲染。
    语法名称只在左侧列表和主区标题显示，重命名只发生在左侧原行；右侧基础设置不重复名称字段。
    日记与代办只显示实际可见正文相关规则；synthetic title 是内部解析事实，不出现在系统语法表格或预览。
    普通笔记语法仍显示标题规则。无效草稿存在时禁止离开，并提供“撤销无效更改”。

编辑器：

    闭合 multiline 块显示为平面代码卡片，卡片头显示语法名称与标识，正文使用等宽字体。围栏、结构前缀和结束分隔不作为普通文本显示或选择。
    点击卡片头只选择卡片；选中后在头部右侧显示“改/删”，修改标识和删除确认均原地完成。正文保持连续编辑，Tab/Shift+Tab 调整正文缩进；在卡片头执行结构缩进时整体移动围栏和正文。
    未闭合 multiline 块继续显示可修复源码和诊断，不渲染成看似完整的卡片。

仓库：

    左侧顺序为“内置数据”日记、代办，“新建仓库”，以及 Local、WebDAV、Browser 分组。行内只保留图标、名称和极简状态；当前普通仓库使用固定前导状态图标，不在行尾追加“当前”文字。
    选中普通仓库后才显示“开”和内联重命名；右侧标题承担名称，状态区不重复名称，并以 22px 紧凑列表展示 adapter、状态和 ID。位置、复制、重扫、重试、冲突恢复和危险操作维持各自所需空间。
    选中内置数据后，右侧显示保存状态、位置、故障、重试和受保护说明，不提供删除、重命名或普通仓库切换。
    永久删除、移除连接、远端清理和故障清理都在右侧原位展开确认；需要名称确认的操作必须输入完整仓库名称，不使用确认弹窗。

其他：

    结构操作使用上下文笔记入口和主区双文档结构；不显示详情。
    引用图谱主区显示画布，详情显示节点和统计；不显示上下文区。
    设置左侧固定选中“界面”，右侧只显示左侧栏宽度；不挂载详情和 Problems。
    搜索与数据当前使用单一主区占位。


3. Problems

Problems 位于主工作区底部，但内容按 Activity 投影：

    普通活动显示 Workspace diagnostics、当前普通仓库运行故障和本 Activity 操作错误。
    Repository 追加普通仓库、内置数据、名称问题、运行故障和本 Activity 操作错误；问题行只定位左侧条目及右侧详情。
    Journal 显示自身正文、语法、仓内和跨仓引用诊断、日记运行故障及本 Activity 操作错误。
    Todo 显示自身语法与 CTN 诊断、代办运行故障及本 Activity 操作错误。
    Syntax 显示当前 owner 的 profile、对应内容诊断、对应运行故障及本 Activity 操作错误。
    Settings 完全不渲染 Problems。

Problems 常态高度为 24px，默认折叠；展开状态和高度按普通仓库保存。左侧固定显示标题和计数，右侧显示最新的五秒短暂反馈，随后恢复 Notes、Journal 或 Todo 的非稳定保存状态；稳定时为空，不显示“已保存”。右侧文本必须省略，不能挤压左侧计数。

状态型故障恢复后自动消失。操作错误按来源 Activity 保留、同消息合并且最多 20 条，问题行提供独立“关闭”；点击正文只返回来源 Activity。新错误不得自动展开 Problems。专注模式隐藏面板但保留错误；右下角不渲染通知浮层。任何破坏性操作都不得放入问题行。


4. 尺度与字体

    活动栏宽度：48px。
    详情折叠宽度：36px。
    主工作区最小宽度：420px。
    面板标题高度：32px 到 34px。
    面板内边距：8px 到 10px。
    常用间距：4px 到 6px。
    树行、输入框和图标按钮：20px 到 24px。
    常规圆角：3px 到 4px。
    Problems 展开高度：120px 到 360px，默认 200px。

    页面标题：16px / 600。
    正文、列表、树：13px / 400。
    控件和辅助文字：12px / 400 或 600。
    编辑器正文：14px；标题使用 strong-weight token。
    代码和符号：12px 等宽字体。
    数字：tabular-nums。

字号、字重和颜色必须通过角色 token 进入样式；Activity CSS 只描述布局和业务状态。


5. 颜色与状态

基础色沿用 VS Code 暗色角色：

    activity #333333
    context/panel #252526
    editor #1e1e1e
    hover #2a2d2e
    selected #37373d
    border #2d2d30 / strong #3c3c3c
    foreground #cccccc / strong #ffffff / muted #969696
    accent #0e639c
    error #f48771
    warning #cca700
    success #6a9955

selected、focus、drag 和 diagnostic 使用背景、文字或细边界表达。普通控件不使用亮色外框，普通任务不使用连续整行色块，阴影只用于菜单、tooltip 和浮层。


6. 共享结构

紧凑 context list：

    笔记、仓库、语法、日记和代办共享行操作与内联编辑结构，但保留各自 view model 与命令。操作只在 selected 行渲染，hover 或单纯 focus 不显示。
    前导图标、主标签和行尾状态使用固定网格列并垂直居中；行尾多个状态必须包在同一对齐容器中。树内输入文字与行高垂直居中。
    操作固定右对齐，顺序为辅助操作“开/用”、“改”、“删”。重命名在原行显示输入框和“确定/取消”，Enter 提交、Escape 取消、失焦不提交；删除在原操作区替换为“确认/取消”。切换选择必须取消未提交状态，失败时保留原地状态并把完整错误投影到 Problems。

结构树：

    用于笔记结构、语法预览和 Todo 详情。缩进随深度移动整行；marker 使用可变文本列。仅支持排序的业务树提供拖放并明确区分上方、下方和内部落点；Todo 详情只允许勾选和定位。

容量：

    树保持固定行高。可见行超过 500 时使用窗口化；窗口化只共享滚动与测量，不合并目录树和结构树的业务语义。

控件：

    Button、ToggleButton、SegmentedControl、Panel、Section、表单行、列表行和空状态由 shared primitives 提供。页面只组合业务布局、局部状态和回调。
