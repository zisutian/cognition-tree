界面样式约定


1. 基准

界面基准是 VS Code 默认暗色主题。整体表现接近编辑器工具：平面、克制、高信息密度、低装饰。

workbench 由活动栏、上下文区、主工作区和详情区组成。活动栏始终存在。上下文区按页面需要出现。详情区按页面需要出现，并可折叠为窄入口。

笔记和结构操作是主要结构样本。笔记代表文档编辑型页面，结构操作代表结构整理型页面。其他页面按任务选择槽位，不继承目录布局。


2. 页面关系

笔记：

    上下文区显示笔记目录。
    主工作区显示可编辑内容，不显示块元数据保留行。
    详情区显示笔记统计、笔记时间、笔记结构和当前块时间；笔记时间不依赖结构选择，当前块时间跟随编辑光标和结构选择。

结构操作：

    上下文区显示可选择的笔记入口。
    主工作区显示源笔记、目标笔记和笔记结构操作。
    详情区不显示。

仓库语法：

    主工作区显示语法配置。
    详情区显示语法预览。
    上下文区不显示。

引用图谱：

    主工作区显示图谱画布和紧凑工具栏。
    详情区显示统计、当前节点、邻接关系和引用排名。
    上下文区不显示。

搜索和数据：

    主工作区承载页面内容。
    上下文区不显示。

设置：

    上下文区使用与笔记目录一致的紧凑列表，按 adapter 分组显示仓库，并以相同的行高、hover、selected 和弱状态表达当前仓库。
    主工作区使用 VS Code 风格的平面高密度纵向结构，不显示详情区。标题栏只保留添加、重新扫描和冲突恢复等图标操作。
    当前仓库摘要显示名称、adapter、保存状态和只读 ID；仓库切换由上下文列表完成，不在主工作区重复提供下拉框。
    位置区按 adapter 显示结构化 location。Local 存在宿主机映射时先显示宿主机路径、再显示服务端或容器内路径；没有映射时以服务端路径为主。WebDAV 显示无凭据 URL；Browser 显示 IndexedDB 数据库名。
    路径使用等宽字体、完整换行和可选择文本，不以省略号替代尾部；每条路径提供复制操作，复制结果进入全局 feedback。
    “重新扫描文件”位于当前仓库操作区，显式触发远端或磁盘读取，不暗示实时 watcher。
    设置页中的“添加仓库”默认折叠；没有健康仓库时的 Setup 页面保持创建表单常显。
    仓库问题在上下文区与健康仓库按 adapter 一起分组；清理、重试和移除连接等操作位于对应问题行。主工作区不重复显示仓库问题区段。
    不受支持的 Local 格式显示手工删除提示、可复制路径和重新检查入口，不提供自动清理入口。
    工作台设置使用独立区段，不与仓库创建表单混排。
    危险操作区位于页面末尾，删除入口不紧邻仓库选择器。删除托管数据需要输入当前 label；WebDAV 的“仅移除连接”和“删除远端数据”保持不同语义与警告。

全局问题面板：

    位于主工作区底部，不属于任何活动页面或详情区。
    统一显示笔记解析错误、语法配置错误和未解析引用；设置活动选中时同时追加仓库问题，原有问题继续保留。
    仓库问题行定位设置上下文中的对应仓库，实际仓库操作仍位于上下文区。
    默认折叠；展开状态和高度按仓库保存。
    专注模式隐藏问题面板。


3. 尺度

    活动栏宽度：48px。
    详情折叠宽度：36px。
    主工作区最小宽度：420px。
    面板标题高度：32px 到 34px。
    面板内边距：8px 到 10px。
    主要间距：6px。
    紧凑间距：4px。
    树行高度：20px 到 22px。
    输入框和按钮高度：22px 到 24px。
    图标按钮宽高：22px 到 24px。
    常规圆角：3px 到 4px。
    分隔线：1px。
    问题面板折叠高度：24px。
    问题面板默认展开高度：200px。
    问题面板展开高度范围：120px 到 360px。
    问题行高度：22px。


4. 字体

    页面标题：16px / 600。
    正文、列表和树：13px / 400。
    控件和辅助文字：12px / 400 或 12px / 600。
    编辑器正文：14px。
    代码和符号：12px，使用等宽字体。
    数字：tabular-nums。

字号和字重通过角色 token 进入样式。activity 样式只描述页面布局和业务状态。


5. 颜色

    活动栏背景：#333333。
    上下文区背景：#252526。
    主编辑背景：#1e1e1e。
    面板背景：#252526。
    hover 背景：#2a2d2e。
    selected 背景：#37373d。
    普通边界：#2d2d30。
    强边界和输入背景：#3c3c3c。
    普通文字：#cccccc。
    强文字：#ffffff。
    弱文字：#969696。
    链接文字：#569cd6。
    主按钮背景：#0e639c。
    错误：#f48771。
    警告：#cca700。
    成功：#6a9955。

选中、聚焦和拖放状态以背景、文字和细边界表达。普通控件不使用亮色外框。诊断通过紧凑图标和行状态表达，不使用连续色条。


6. 共享结构

目录树：

    用于笔记目录和结构操作入口。
    前置区域使用 13px 符号槽。
    文件夹显示折叠符号和文件夹图标。
    笔记显示文档图标，业务状态可替换该图标。
    行操作位于右侧，只在 hover 或 selected 时显示。

结构树：

    用于笔记结构、语法预览和结构操作中的块结构。
    前置 marker 是可变文本列，可以完整展示“组分”“理解”“定义”等名称。
    缩进按结构深度和当前缩进显示宽度计算，整行一起缩进。
    选中子树以整体背景表达。
    拖放落点按上方、下方和内部位置表达。

树容量：

    目录树和结构树保持固定 22px 行高。
    可见行不超过 500 时保留完整递归结构；超过 500 时使用窗口化渲染。
    窗口化只共享滚动和行高机制，目录行与结构行继续使用各自的数据、缩进和交互结构。

符号槽：

    用于目录树图标、引用图谱列表标记、工具按钮和紧凑状态。
    选中后符号颜色跟随文字转为强文字。

共享控件：

    Button、ToggleButton、SegmentedControl、Panel、Section、表单行、列表行和空状态由 shared primitives 提供。
    二选一或多选项切换使用 SegmentedControl。
    表单控件使用背景态和文字态表达 hover、focus 和 selected。


7. 视觉约束

常规面板、列表、表单和状态区保持平面。阴影只用于菜单、tooltip 和浮层。

主工作区和详情区保持中等偏高的信息密度。标题只用于页面和面板层级，行内信息用 meta、符号、弱文字和紧凑间距表达。

页面之间保持槽位关系稳定。没有上下文内容的页面不渲染空上下文区；没有详情内容的页面不渲染空详情区。
