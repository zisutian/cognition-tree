## 基线证据

- 临时数据的 Chromium 复现：编辑第二个 Provider 时，右侧仍显示第一个 Provider。
- 笔记、日记、待办在 1280×720 的对象、正文、详情关联正确；其布局作为设置的参照。
- 1440×900 的仓库正常状态主区仅展示危险操作；搜索及 Agent 初始页展示空详情。
- 所有检查使用独立测试数据，不读取或改变个人业务内容。
