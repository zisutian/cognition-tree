## 基线与回归证据

- Chromium 先复现编辑第二个 Provider 时右侧仍显示第一个 Provider，再修复统一选中对象；此回归随目录重整保留。
- 笔记、日记、代办在 1280×720 的目录、正文与详情关系作为设置参照；保留既有密度、字体和编辑规则。
- 仓库健康页面补入“继续编辑笔记 / 打开仓库”，危险操作移至末尾；空搜索和未选择会话不再占用详情栏。
- Provider、Profile 和令牌由各目录组直接创建。保存和放弃固定在主区头部；一次性明文、认证、撤销和迁移确认在主区。
- 草稿版本过期后改回原值再刷新，原实现会错误解除保护；通用草稿及系统表单的三项新增回归先失败后通过，浏览器同时验证目录与活动继续被阻止。
- 审计主区移除重复标题，技术详情默认折叠。键盘选择其他记录时详情与记录一致；刷新失败保留当前记录。
- 布局检查与流程检查分开，几何与遮挡使用真实浏览器测量；CSS 段落锁定和退役选择器清单被删除，主题词汇、尺寸常量和独立输出契约保留。
- 模型夹具的固定 ID 用尽后改为生成唯一 ID，避免长列表测试实际反复覆盖同一对象；配置和账本仍写入真实临时文件系统。
- 浏览器响应延迟夹具、HTTP 请求上下文、重启计时器、事件流和临时目录均由创建方清理；图谱稳定等待使用可观察几何。
- 敏感流程关闭 trace、截图和自动 DOM 错误快照；断言不输出密钥。布局截图仅包含无秘密的测试数据。

## 验证边界

本轮验证的是 Linux Chromium 桌面、真实临时文件系统、HTTP 和受控子进程。
输入法回归使用浏览器 composition 事件，未覆盖所有操作系统输入法。
确定性模型协议不能替代真实 Ollama、远程模型或 Codex 登录服务验证；这些真实服务本轮未连接。
其他浏览器、操作系统和真实断电未验证。进程终止测试只证明进程恢复路径，不作为断电持久性证据。
