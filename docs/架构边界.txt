架构边界


1. 逻辑模块

UI：

    应用入口、应用外壳和用户可见功能界面。
    负责展示状态、接收输入和触发命令。
    共享 UI 渲染结构属于 UI 层。

Workspace：

    应用运行边界和 workspace 模型边界。
    包含 workspace 数据模型、运行时聚合、session、command、workflow 和 view model。
    Workspace Model 承载笔记、目录树、块文本移动和 workspace action 的纯模型规则。

CTN Parser：

    CTN 原文解析核心。
    把 .ctn source 和 CtnSyntaxProfile 解析成结构结果、诊断和引用信息。

CTN Syntax：

    CTN 语法核心。
    包含 CtnSyntaxProfile、默认语法、语法配置解析、validation、draft 和 tone 规则。

Editor：

    编辑器技术适配层。
    提供编辑器集成能力。

Storage：

    前端持久化端口和存储适配器。
    承载 workspace 数据契约的读写适配。

Server：

    Node HTTP API 和本地文件仓库读写。


2. 当前依赖关系

    UI -> Workspace
    UI -> CTN Parser
    UI -> CTN Syntax
    UI -> Editor
    Workspace -> CTN Parser
    Workspace -> CTN Syntax
    Workspace -> Storage
    Storage -> Workspace Data
    Storage -> CTN Syntax
    CTN Parser -> CTN Syntax


3. 隔离边界

    Workspace 不依赖 UI。
    Storage 不依赖 UI。
    CTN Syntax 不依赖 Workspace 和 UI。
    CTN Parser 不依赖 Workspace 和 UI。
    Workspace Model 不依赖 CTN Syntax、Storage 和 React。
    React 组件、交互状态和视觉结构位于 UI 层。
