架构边界


1. 文档边界

    本文记录目标目录职责和依赖方向。
    本文采用最精简的正向描述。
    文档边界章节保留。


2. 目录职责

src/app：

    应用组合根，装配 application、ui、storage、editor。

src/application：

    应用用例编排，管理 session、命令流程、加载保存、状态和端口调用。

src/ui：

    shell：应用外壳，提供导航、侧栏框架、主区域和详情区域 slot。
    activities：用户功能界面，承载 activity 视图、局部交互状态和 view model。
    shared：UI 共用组件和展示结构。

src/workspace：

    workspace 业务核心，承载数据模型、命令、查询、索引和语法上下文。

src/ctn：

    parser：CTN 原文解析，输出结构、诊断和引用信息。
    syntax：CTN 语法核心，提供 profile、默认语法、配置解析和校验。

src/storage：

    持久化端口和存储实现，负责 workspace 数据和 syntax source 读写。

src/editor：

    编辑器技术适配，提供编辑器组件、事件桥接和语法能力集成。

server：

    本地 HTTP API 和文件仓库执行端。


3. 依赖方向

    src/app -> src/application、src/ui、src/storage、src/editor
    src/ui -> src/application、src/workspace、src/ctn、src/editor
    src/application -> src/workspace、src/ctn、src/storage
    src/workspace -> src/ctn
    src/storage -> src/workspace、src/ctn
    src/editor -> src/ctn
    server -> Node HTTP、文件系统、本地文件仓库 DTO
