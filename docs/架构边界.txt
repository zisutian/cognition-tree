架构边界


1. 文件职责

    架构边界文档：

        记录系统模块边界。
        记录依赖与归属。

    不允许轻易进行修改

2. 模块

UI：

    应用入口、应用外壳、用户可见功能界面。
    应用运行装配。
    App Runtime（src/app/runtime）：React 生命周期、workspace 持久化装配、仓库路径、保存状态。
    展示状态、接收输入、触发命令。
    共享 UI 渲染结构。

Workspace：

    应用运行边界和 workspace 模型边界。
    数据模型、actions、queries、index、runtime。
    Model：workspace 数据类型、笔记、目录树的纯模型逻辑。
    Actions：workspace 修改入口，包含简单修改和跨笔记复合修改。
    Queries：结构读取、index 读取、上层查询入口。
    Index：解析结果、引用图、高频查询加速、索引失效逻辑。

CTN Parser：

    CTN 原文解析核心。
    .ctn source 和 CtnSyntaxProfile 到结构结果、诊断、引用信息的转换。

CTN Syntax：

    CTN 语法核心。
    CtnSyntaxProfile、默认语法、语法配置解析、validation、draft、tone 配置。

Editor：

    编辑器技术适配层。
    编辑器集成能力。

Storage：

    前端持久化端口和存储适配器。
    workspace 数据契约读写适配。
    可恢复缓存载体读写。

Server：

    Node HTTP API。
    本地文件仓库读写。


3. 依赖与归属

    UI -> Workspace、CTN Parser、CTN Syntax、Editor；App Runtime -> Storage；归属展示、交互状态、应用运行装配。
    Workspace -> CTN Parser、CTN Syntax；归属模型、修改、查询、索引。
    Storage -> Workspace Data、CTN Syntax；归属持久化端口、适配器、缓存读写。
    CTN Parser -> CTN Syntax；归属 CTN 原文解析。
    Server -> HTTP API、本地文件仓库读写。
