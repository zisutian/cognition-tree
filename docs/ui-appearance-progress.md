# Dark Modern 样板与验证记录

基线：`80ab630`。本轮先完成真实笔记和 Provider 设置样板，在 1280×720、1440×900 下验证并交由用户确认，然后继续其余页面。共享基础直接应用于生产调用方，没有独立演示版或主题开关。

当前阶段：样板实现与验证，尚未获得视觉确认。其余设置表单的下拉框、复选框和纵向布局推广仍待确认后进行；不能把共享配色生效或既有流程通过视为全活动视觉验收。

## 职责与迁移清单

| 组件族 | 基线中的重复路径 | 当前所有者及调用方 | 验证场景 |
|---|---|---|---|
| 按钮 | 活动栏、列表、树、菜单、ChoiceGroup、ToggleButton 各自渲染 button | Button 拥有普通 React 原生按钮；语义组件组合它并拥有选择、快捷键、拖放行为 | 点击、键盘、焦点、禁用、树重命名与菜单 |
| 复选框 | Todo 详情和周期表单直接渲染 input | CheckboxControl 拥有普通 React checkbox；Todo 与 Provider 使用它 | 勾选、周期选择、草稿保护 |
| 编辑器 checkbox | DOM widget 独立定义尺寸与颜色 | 共享视觉契约；CodeMirror 仅保留宿主位置、事件与文档命令 | 编辑器任务切换及既有撤销回归 |
| 表单 | 紧凑表单只有标签列；工具面板重复覆盖控件尺寸 | FormLayout 显式 columns/stacked；FieldRow 拥有标签、说明与错误关联 | Provider 纵向对齐、长值、保存/放弃 |
| 标题与目录 | AppFrame 单独实现侧栏标题；笔记单独排列目录动作 | PanelHeader 拥有面板标题；CompactContextGroupHeader 拥有目录标题与动作 | 标题固定、动作不遮挡、目录折叠 |
| 状态与问题 | Problems 头部同时承担底栏状态 | 控制器拥有唯一投影，StatusBar 与 ProblemsPanel 分别展示 | 全宽底栏、持续草稿消息、问题筛选与尺寸 |

原生控件所有权检查已覆盖共享组件内部，Todo 原生控件文件例外已删除。检查继续使用完整生产扫描与现有模块依赖规则。

## 样板与证据

`e2e/workbench-appearance.pw.ts` 使用真实临时服务、文件存储及浏览器，生成两种尺寸的 `notes.png` 和 `provider.png`。笔记样本使用真实 CTN 内容；Provider 为无明文密钥的测试对象。截图不代表真实模型服务验证。

同一测试文件验证控件键盘操作、分组折叠后输入保留、导航阻止、保存与放弃，以及问题面板关闭后不占编辑空间、重新打开后保留筛选。既有八活动布局与业务流程继续验证共享基础的调用方。

## 当前验证结果

- 全量单元与集成测试：253 个文件、1275 项通过。旧折叠头部的静态交互断言已移入真实浏览器场景。
- Chromium：共 59 项场景。首次全量使用 2 个 worker，56 项通过；修正搜索状态和设置刷新按钮的定位后，与一次超时的 Agent 场景一起针对性复跑，3 项全部通过。Agent 超时发生在同时运行全量单元测试的首次运行中，独立复跑为 10.4 秒；未放宽超时门槛。
- 问题面板关闭后的焦点返回：补充浏览器断言，独立通过；筛选保留与编辑区高度同时验证。
- 两种尺寸的八活动布局、长名称、长路径、长列表和侧栏键盘调整通过。四张无敏感信息的样板截图已人工查看并留存到 `.artifacts/ui-dark-modern/{1280x720,1440x900}/`。样板测试原始输出位于 `.artifacts/test/playwright/`，后续可重新生成并留存。
- 前后端构建与包体积检查通过；保留 8 个活动懒加载，初始 JS 为 735427 字节，未调整门槛。
- 文档链接、锚点和命令入口检查通过。类型检查通过；架构检查 8 个文件、43 项通过，两者继续由每次提交的钩子执行。

最终容量对照、开发与编译后服务入口复核，以及全活动视觉收口在用户确认样板后执行。真实模型、其他浏览器/平台与真实断电不在当前样板验证证据范围内。
