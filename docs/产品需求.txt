产品需求


1. 产品定位

认知树是本地优先的可配置语法结构化笔记系统。

它面向概念、定义、组分、理解、引用和结构整理。`.ctn` 原文是写作和存储的主要格式；Markdown、HTML、PDF 和纯文本属于导出方向。


2. 核心对象

仓库：

    长期知识域，持有笔记原文、目录树和仓库语法。仓库只持久化真实事实；标题与时间从 canonical 笔记 source 推导。Local 仓库以真实目录和 `<标题>.ctn` 作为可见工作树，以根部 `.ctn/` 保存身份、顺序、语法、块元数据和事务事实。HTTP 模式的仓库可以由 Local 或动态注册的 WebDAV adapter 提供，Browser 模式使用独立的 Browser adapter；adapter 之间不自动传输内容。repository ID 由 catalog 自动生成，workspace ID 独立生成。

文件夹：

    仓库内的组织节点，用于浏览、归类、移动和新建落点。

笔记：

    一个相对完整认知对象的原文内容单元。应用内 canonical source 以标题 metadata 和标题内容行开头；标题与创建、修改时间均从该 header 推导。Local 的可见 `.ctn` 文件只保存编辑器正文，文件名去掉扩展名后与首行标题一致，canonical metadata 由隐藏 sidecar 重建。空标题可作为 draft 和诊断保留，但不能发布为 Local 文件。

块：

    由一行及其缩进子树组成，是阅读、选择、移动和结构整理的基本单位。配置语法后，每个块具有稳定标识、创建时间和更新时间；这些持久化元数据不占用编辑区域。

仓库语法：

    仓库级符号解释方案，决定行首规则、行内规则、显示名称、缩进显示宽度和视觉提示。

引用：

    局部概念引用和全局概念引用。全局概念引用形成笔记级引用图谱；重复标题目标是 ambiguous 候选，不生成任意确定边，自引用保留为 self-loop。


3. 产品特征

思维优先：

    编辑器围绕概念结构和思维链路组织，而不是围绕版式排版组织。

缩进即作用域：

    缩进表达父子关系、展开关系和局部语义范围。

符号即语义：

    行首符号、行内符号和多行块符号映射为明确的语义类型。

仓库级语法：

    一个仓库使用一份当前语法，仓库内笔记共同按该语法解析。

本地优先：

    用户持有完整笔记原文、目录结构和语法配置。Local 仓库中的界面文件夹与磁盘目录一致，界面笔记与标题命名的 `.ctn` 文件一致。

原文权威：

    语法配置影响解析和显示，笔记原文保持独立。

开放数据：

    Local 可见内容由普通目录和 `.ctn` 正文组成；仓库内部事实由根部 `.ctn/` 中的 JSON、TOML、sidecar 和 WAL 组成，便于检查并保持事务一致性。

个人仓库：

    产品面向单个使用者及其受控设备。服务端 bearer token、WebDAV 凭据和 writer fencing 保护个人部署与同一使用者的多个实例；产品对象中没有用户、角色、共享权限或多人协作状态。


4. 当前范围

已具备能力：

    在仓库活动中创建、选择和切换 Local/WebDAV 仓库；在 Browser 模式创建、选择和切换 Browser 仓库。
    为 repository 自动分配稳定 ID，并为初始内容独立分配 workspace ID。
    动态注册无认证或 Basic 认证的 WebDAV 连接；空目标初始化为 v3 仓库，已有 v3 内容保持为远端事实。
    删除 Local/Browser 托管数据；对 WebDAV 分别提供仅移除连接和删除远端托管数据。
    远端删除通过 ETag CAS 发布永久 tombstone，随后清理托管 generations，并保留目标中的无关文件。
    将 Local 文件夹和笔记投影为真实目录与 `<标题>.ctn`，并在首次加载、同步和手动重新扫描时识别外部新增、编辑、删除、重命名和移动。
    使用 Local 隐藏顺序清单保留同级手工排序；保留非 `.ctn` unmanaged 文件，并阻止界面整体删除包含 unmanaged 文件或 symlink 的目录。
    创建、编辑、删除、重命名和移动笔记。
    创建、重命名、删除和移动文件夹。
    编辑 CTN 原文，并用 Tab 表达结构层级；在多行块内保持代码内容缩进，不改变 CTN 结构。
    在保留活动栏的专注模式中编辑当前笔记，并在退出后恢复原有工作台布局。
    用仓库语法解析整个仓库，在编辑器中装饰当前笔记并展示结构树。
    在笔记详情中分别查看笔记的创建与修改时间，以及当前结构块的创建与更新时间。
    通过受控界面编辑仓库语法。
    在源笔记和目标笔记之间移动整棵块子树。
    在单篇笔记内调整结构块位置。
    通过 Ctrl+点击跳转局部块引用和全局笔记引用，并在多目标时明确选择落点。
    查看笔记级引用图谱和局部引用关系。
    在工作台全局问题面板中统一查看笔记解析错误、语法配置错误和未解析引用，并定位到笔记行或语法字段。
    创建、切换和删除仓库，查看自动生成的仓库 ID、adapter 对应的结构化位置、存储状态和保存状态，并按仓库保存工作台目录宽度与问题面板状态。Local 位置显示真实服务端路径，并可显示只用于展示的宿主机路径；WebDAV 显示无凭据 URL；Browser 显示 IndexedDB 数据库名。
    在仓库活动中手动重新扫描当前仓库；外部修改不通过 watcher 或 SSE 实时推送。
    在 catalog 中分别呈现健康仓库、损坏连接和仍在执行远端清理的条目，不让单仓问题阻断其他仓库。
    在网络不可用时继续编辑已有缓存的远端仓库，并在恢复后自动同步或明确报告 revision 冲突。

保留入口：

    搜索。
    数据视图。

后续能力：

    全文检索、导出、导入、反向链接、派生索引、全文统计、同步、插件、桌面封装和 AI 辅助整理。

复杂图谱能力：

    概念级图谱、块级图谱和时间演化图谱。


5. 语法范围

默认语法：

    顶格普通行：顶格概念
    :：定义
    >：自我理解
    -：组分、分类、例子和枚举项
    ?: 疑问
    ```：多行块
    `...`：行内代码
    <...>：局部概念引用
    [[...]]：全局概念引用
    \：并列分隔

仓库语法覆盖：

    顶格概念名称。
    行首规则名称、符号和颜色。
    行内规则名称、符号和颜色。
    多行块规则名称、符号和颜色。
    Tab 显示宽度。

仓库语法边界：

    缩进层级和父子关系来自原文结构。
    一个仓库可以保存多份有序语法文件，列表中选中的文件是当前启用语法。
    语法名称在仓库内按 trim、NFKC 和 en-US lowercase 规范化后唯一。
    单篇笔记和单个文件夹没有独立语法。
    普通笔记正文不内嵌语法配置。
    语法界面只暴露受控字段、受控颜色和受控规则类型。


6. 成功状态

    用户可以不用 Markdown 记录复杂概念笔记。
    用户可以用缩进表达作用域和层级。
    用户可以维护多份仓库级语法并明确选择当前启用项。
    用户可以通过结构树判断笔记结构。
    用户可以在笔记之间移动整棵块子树。
    用户可以在单篇笔记内整理结构块。
    用户可以通过引用图谱查看笔记间关系。
    用户可以直接检查仓库中的原文、目录和语法文件。
