4. 双机原则

代码：

    Windows 和 Linux 可以各自保留一份代码仓库。

数据：

    当前笔记数据互通应通过同一个 HTTP 后端服务完成。
    Docker 后端服务作为后续独立阶段引入。
    不依赖同步代码目录来同步笔记数据。

路径：

    主项目避免长期放在中文路径、空格路径或同步盘特殊目录下。

换行：

    仓库统一使用 LF。
    Windows 批处理和 PowerShell 文件保留 CRLF。
