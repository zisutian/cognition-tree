3. Git 规则

仓库使用 LF 作为统一换行。

.gitattributes 已固定：

6. 第一阶段环境与技术栈对应关系

    Tauri 2 需要 Rust、系统 WebView 依赖和平台构建工具。
    Vite、React、TypeScript、CodeMirror 6、Vitest 和 Playwright 需要 Node.js LTS 与 pnpm。
    Rust 后端和 Tauri commands 需要 rustup、cargo 和对应平台 toolchain。
    SQLite + JSON1 需要 SQLite 运行库；开发和调试建议安装 sqlite3 命令行工具。
    Playwright 首次运行可能需要安装浏览器测试运行时。
    当前第一阶段不做移动端，因此暂不需要 Android Studio、Android SDK、Xcode 或 iOS 配置。

参考：

    Tauri 2 前置要求：https://v2.tauri.app/start/prerequisites/
