1. 推荐开发方式

主运行形态：

    Docker 后端 + 浏览器前端

主开发环境：

    Linux

原因：

    Docker 后端保存笔记数据，浏览器作为跨平台界面。
    Windows 和 Linux 访问同一个 Docker 服务即可看到同一份 workspace。
    Linux 仍适合日常开发、脚本、测试、Git、Node 和 Docker。
    Tauri 桌面 GUI、Windows 安装包、Linux WebKitGTK 依赖当前暂缓保留。


2. 推荐目录

Linux：

    /home/zisu/code/cognition-tree

Windows：

    C:\Users\thefu\Documents\cognition-tree

避免把主项目长期放在中文路径、空格路径或同步盘特殊目录下。


3. Git 规则

仓库使用 LF 作为统一换行。

.gitattributes 已固定：

    * text=auto eol=lf

Windows 批处理和 PowerShell 文件保留 CRLF：

    *.bat
    *.cmd
    *.ps1

7. 第一阶段环境与技术栈对应关系

    浏览器前端需要 Node.js LTS 与 pnpm。
    Vite、React、TypeScript、CodeMirror 6、Vitest 和 Playwright 运行在前端工具链上。
    Docker 后端负责统一运行 API 服务和持久化文件库。
    Docker volume 保存 workspace.json 和 notes/*.ctn。
    SQLite + JSON1 需要 SQLite 运行库；开发和调试建议安装 sqlite3 命令行工具。
    Playwright 首次运行可能需要安装浏览器测试运行时。
    Tauri 2 需要 Rust、系统 WebView 依赖和平台构建工具，但当前暂缓。
    当前第一阶段不做移动端，因此暂不需要 Android Studio、Android SDK、Xcode 或 iOS 配置。

参考：

    Tauri 2 前置要求：https://v2.tauri.app/start/prerequisites/
