环境准备

版本：0.1
日期：2026-05-20


1. 推荐开发方式

主运行形态：

    Docker 后端 + 浏览器前端

主开发环境：

    Linux

原因：

    Docker 后端保存笔记数据，浏览器作为跨平台界面。
    Windows 和 Linux 访问同一个 Docker 服务即可看到同一份 workspace。
    Linux 适合日常开发、脚本、测试、Git、Node 和 Docker。
    桌面路线不在当前分支维护；需要时从 main 或 git 历史恢复。


2. 推荐目录

Linux：

    /home/zisu/code/cognition-tree

Windows：

    C:\Users\thefu\Documents\cognition-tree

避免把主项目长期放在中文路径、空格路径或同步盘特殊目录下。


3. Git 规则

仓库使用 LF 作为统一换行。

.gitattributes 已固定：

    * text=auto eol=lf

Windows 批处理和 PowerShell 文件保留 CRLF：

    *.bat
    *.cmd
    *.ps1


4. Web / Docker 环境准备

需要安装：

    Git
    Node.js LTS
    pnpm
    Docker
    Docker Compose

Node.js / pnpm：

    安装 Node.js LTS
    corepack enable
    corepack prepare pnpm@latest --activate

验证命令：

    git --version
    node -v
    npm -v
    pnpm -v
    docker --version
    docker compose version

目标运行方式：

    Docker 后端提供 HTTP API。
    浏览器访问前端页面。
    Docker volume 持久化 workspace.json 和 notes/*.ctn。
    Windows 和 Linux 通过浏览器访问同一个后端服务，实现双端互通。

当前代码状态：

    已有 Node HTTP 后端最小服务。
    已有文件仓库读写逻辑。
    已有服务端测试。
    Dockerfile、compose 文件、HTTP 前端存储适配器后续补齐。


5. Linux 本机开发环境

需要安装：

    Git
    Node.js LTS
    pnpm
    Docker Engine 或 Docker Desktop
    Docker Compose

可选安装：

    sqlite3
    libsqlite3-dev

说明：

    SQLite 当前是后续索引缓存方向，不是第一阶段启动前端和后端的硬性依赖。
    Playwright 首次运行浏览器测试时，可能需要安装浏览器测试运行时。

Ubuntu / Debian 常用命令：

    sudo apt update
    sudo apt install git curl build-essential sqlite3 libsqlite3-dev
    corepack enable
    corepack prepare pnpm@latest --activate

Docker 安装建议：

    优先使用 Docker 官方文档安装 Docker Engine 或 Docker Desktop。
    安装后确认当前用户可以运行 docker 命令。

验证命令：

    git --version
    node -v
    npm -v
    pnpm -v
    docker --version
    docker compose version
    sqlite3 --version

7. 本地开发命令

安装依赖：

    pnpm install

浏览器前端开发：

    pnpm dev

Node 后端服务：

    pnpm server

测试：

    pnpm test

类型检查：

    pnpm check

生产构建：

    pnpm build

后端脚本语法检查：

    node --check server/index.mjs
    node --check server/noteApiServer.mjs
    node --check server/noteFileStore.mjs


8. Docker 运行定位

Docker 在当前路线中不是单纯验证环境，而是主运行后端。

第一版目标：

    后端服务容器化。
    workspace.json 和 notes/*.ctn 放入 Docker volume。
    浏览器前端通过 HTTP API 访问后端。
    Windows 和 Linux 可访问同一个服务和同一份数据。

第一版不承诺：

    多用户账号和权限。
    公网部署安全模型。
    桌面安装包。
    移动端应用。


9. 双机工作流
